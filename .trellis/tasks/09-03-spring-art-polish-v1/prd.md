# 春季美术与手感精修 v1

## Goal

打磨「起床出门 → 种田 → 收获入包 → 回家」中的小屋、常用物品和种田动作。用户于 2026-09-03 确认首批实施范围。

## Confirmed facts

- 春季 v10 与既有真人门禁已通过；保留规则、物品 ID、九种外观与 v10 存档。
- Cottage 使用技术占位，地图拥有床、入口、出口和宠物点位的稳定身份。
- 正式工具仍是通用矩形；Gate A 候选限本地开发，未获正式 CDN 采用。
- 六种种子共用袋子，鱼获/鱼竿和部分采集物无专用图标。
- 历史素材预算为 0；既有完整 VectoRaith、Ninja、GARDENS 图集已登记发布。

## Requirements

1. 自家小屋统一木作、地板、窗、床和有限生活陈设；保留稳定 ID、宠物点位与床/出口功能。收紧空大厅的布局，陈设与 Collision 对齐；旧坐标落在新障碍时复用既有 reconcile 安全入口逻辑。
2. 当前全部物品可辨识；种子保留袋子语义与作物标识，鱼获通过轮廓和配色区分。
3. 图标在快捷栏、背包、送礼和鱼获结果中一致，并保留名称、数量、键盘/触摸语义。
4. 砍树、锄地、播种、浇水和收获有独立四方向姿态与接触反馈，正式路径不依赖 Gate A；九种角色不得在动作中换人。
5. ActionTimeline 只在 impact 发出一次命令，取消/切图后清理表现，失败不播放成功效果。
6. 保持既有图集原始 bytes；缺少的小型图形采用源码定义的原创像素 UI/运行时绘制，不新增静态二进制或外部素材依赖。

## Acceptance Criteria

- [x] 本地浏览器可查看小屋和种田动作；记录截图，不代签真人验收。
- [x] 全部 25 个 item ID 有正式图标，种子、鱼获和采集物在消费面一致。
- [ ] 九种外观一致，四向工具对齐；重复输入只触发一次规则调用，收尾恢复站立/持物。
- [x] 最小类型检查与 client build 通过；小屋 decoder、稳定对象、宠物路径、床/出口通道与旧坐标恢复满足合同。
- [x] 无数据库连接、schema/migration、第三方依赖、付费购买和 Git 图片二进制。

## Out of scope

其他住宅/商店改造、Farm/Town 大构图、新玩法/存档版本、分层换装、剧情/节庆、动态灯光系统、远征和生产部署。
