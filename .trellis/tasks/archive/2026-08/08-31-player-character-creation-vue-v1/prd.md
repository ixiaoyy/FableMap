# 当前主线角色创建与选择

## Goal

在当前 Vue 3 + Phaser 4 + GameSession 主线中，为首次进入农场增加真正生效的角色创建/选择流程。旧版角色创建仅作为交互参考，不恢复旧 React/localStorage 实现，也不沿用已经确认不符合当前美术方向的 Ninja/Samurai 素材。

## Requirements

- 角色选择结果必须改变世界内玩家精灵，并随当前 IndexedDB 本地存档持久化；不得只做不生效的展示页面。
- 优先调查允许商用和再分发、动画合同完整、风格与当前地图/NPC协调的开源多角色或分层换装素材。
- 若采用分层换装，至少核对发型、上衣、下装、鞋子各层在待机和四向移动动画中的帧布局、锚点、遮挡顺序与组合许可。
- 当前 VectoRaith `farmer` 的 Original/ReColor/ReShade 只是同一角色的细微调色，不能包装为多个不同角色选项。
- 不接入账号、API、数据库或云存档；继续使用单浏览器 profile 的单份本地农场。
- 现有存档必须可安全继续；新游戏只有在用户最终确认角色后才创建，不能在浏览角色时覆盖进度。
- 新素材必须遵循项目素材清单、固定来源/版本、许可证、哈希与同源 CDN 路径约束；仓库不提交第三方图片二进制。
- 不迁移或恢复旧版 localStorage 外观字段，只为当前 GameSession 存档定义必要的新字段与兼容路径。

## Acceptance Criteria

- [x] 首次新游戏先进入精修后的角色创建页，继续游戏不重复打断。
- [x] 至少提供有明显视觉差异且风格一致的角色外观选择，最终数量由素材调研结果确定。
- [x] 选择在角色预览、世界玩家精灵、室内外切图和存档恢复后保持一致。
- [x] 键盘、鼠标和触屏均可完成选择、返回与最终确认。
- [x] 选择过程不覆盖已有存档；替换已有农场需保留明确的二次确认。
- [x] 页面在桌面、手机和 200% zoom 下无关键内容遮挡或不可达状态。

## Notes

- 已确认：旧角色创建流程不能完全恢复，旧版所用角色素材不正确。
- 已核对：当前正式玩家只使用一套 VectoRaith farmer；同包 ReColor/ReShade 不足以形成可信的多角色阵容。
- 已核对：当前已登记的 VectoRaith NPC demo 实际包含 8 个同风格角色，每个角色均为 16×32、四方向、三帧动画；可直接作为同风格的角色预设来源，但该包不是分层换装系统。
- VectoRaith NPC 完整包官方列出 424 个角色（含配色变体），但属于付费自定义许可素材，仍然不是发型/衣装/鞋子独立组合。
- 开源候选 `16x Pixel Art World` 为 CC0，提供角色 base、hat、shirt、pants 的独立图层与 idle/walk 动画；优点是许可清晰、可组合，缺点是人物比例和当前 VectoRaith 16×32 风格存在明显差异，且没有明确独立 hair/shoes 层。
- OpenGameArt `customizable character pack` 为 CC0，包含 skin、shoes、pants、tops、hair 和 16 个样例；但分层源文件只提供 XCF，样例是另一套较矮的现代像素风，直接接入会造成美术割裂并增加素材导出流程。
- Universal LPC 功能最完整，但采用 64×64 合同，且素材许可证混合 CC-BY-SA/GPL/OGA-BY/CC0，不符合当前项目默认许可与 16×32 美术边界，暂不采用。
- 已确认：第一版优先把 VectoRaith demo 的 8 个动画角色做成真实预设选择，并保留现有 farmer 作为旧存档兼容外观；独立发型/上衣/下装/鞋子作为后续素材门槛，不用风格不合的包勉强拼接。
