# 东方田园首页改版

## Goal

把当前简陋的深色技术启动页替换为具有“东方田园画卷”辨识度的镜像岛首页，让玩家在第一屏立即理解这是一个可直接开始、使用本地存档的单人农场生活世界。

## Background

- 用户提供的参考图确定了视觉方向：明亮山水田园主视觉、左侧纸木牌式品牌面板、右上角本地存档状态、底部轻量信息带。
- 公开 `/` 仍是无账号本地试玩入口；新游戏、继续游戏、角色创建、加载、错误恢复及 IndexedDB 存档合同保持不变。
- 当前首页实现位于 `apps/mirror-island/client/src/App.vue` 与 `style.css`，游戏内 HUD 和 Phaser 世界不在本次重做范围。
- 正式图片不得进入 Git，必须通过不可变 `game/media/v1` 对象、manifest 和同源代理加载。

## Requirements

- 首页采用原创、无文字、无按钮的东方田园背景，页面文字与控件继续由可访问的 HTML/CSS 渲染。
- 菜单状态使用画卷式主面板承载“镜像岛”“归园启程”、产品简介、新游戏与继续游戏；已有存档时明确显示可继续，无存档时继续按钮禁用。
- 初始化、加载、错误状态复用同一视觉语言，错误文案必须保留恢复动作。
- “新游戏会覆盖本地存档”的确认、角色创建和 IndexedDB 检测逻辑不得改变。
- 桌面布局接近参考图；窄屏改为单列且保持主按钮、存档风险文案和素材鸣谢可见。
- 支持键盘焦点、足够对比度、200% zoom 与 `prefers-reduced-motion`。
- 不新增账号、OIDC、云存档、服务端请求、数据库访问或新的游戏系统。
- 生成素材须记录 prompt、尺寸、MIME、bytes、SHA-256 与不可变对象 key；Git 跟踪图片二进制保持为零。

## Acceptance Criteria

- [x] 在 16:9 桌面首屏中，东方田园主视觉、纸木牌主面板、存档状态和两个主要操作形成清晰层级。
- [x] 新游戏、继续游戏、角色创建、加载与错误恢复行为与改版前一致。
- [x] 无存档时继续按钮不可用；有存档时状态提示和继续入口可用；清除站点数据风险文案仍可见。
- [x] 手机宽度和 200% zoom 下没有关键内容裁切、横向溢出或不可达按钮。
- [x] 键盘可遍历操作；焦点、禁用、加载和错误状态清楚；减少动态效果偏好得到尊重。
- [x] 生产背景图通过 `/game-media/v1` 加载，并完成 manifest、来源记录和校验脚本登记，仓库不跟踪图片二进制。
- [x] `npm --prefix .\apps\mirror-island run typecheck` 与 `npm --prefix .\apps\mirror-island run build:client` 通过。
- [x] 浏览器人工验收覆盖桌面、手机、200% zoom、新/旧存档状态及身份服务不可达时无 OIDC 请求。

## Out of Scope

- 游戏内 HUD、角色创建器内部布局和 Phaser 场景美术重做。
- 数据库、migration、登录、论坛、云存档和多人能力。
- 直接复用参考图中已经烘焙的文字、按钮或品牌元素。
