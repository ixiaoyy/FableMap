# Day 1-7 留存纵向切片

## Goal

把现有镜像岛 Stardew Core 从“已有地图、动作和 NPC，但反馈与目标不足”的玩法验证版，收敛为可从新游戏连续体验到 Day 7 的首周留存切片：玩家每隔一两天获得一个可感知的新反馈或新目标，现有种田、采集、商店、NPC、关系和存档形成闭环，并在 Day 7 对镜门另一边产生兴趣。

## Confirmed Repository Facts

- 当前基线为 Phaser 4.2.1 + Vue 3 + domain `GameSession` + IndexedDB；正式世界有 Farm、Town、Cottage、Seed Shop、Blacksmith、五栋住宅、Foothills、Lakeshore 共 12 个区域和 8 名 NPC。
- 当前 `StoredGame` / `GameState` 为 v7；背包 decoder 强制恰好 24 槽，扩为 32 槽需要显式 v7→v8 迁移，不能只改 UI 常量。
- 新游戏自带锄头、水壶和斧头；现有制作底层只有“3 木材→木斧”一个配方，但生产 UI 没有制作按钮，只有开始菜单仍宣称“采集、制作、种田”。本阶段应移除误导文案并保留底层命令/服务，不需要删除制作实现。
- Farm 有 8 块农田；水壶当前只对点击的一块农田调用 `FarmingSystem.use`，Lv2 三格浇水需要 domain 根据面向与网格关系一次原子解析多目标，Phaser 不得自行循环改状态。
- 世界有 38 棵可一次采集的树，共可产出 114 木材；7 个石头点目前没有石料物品或敲石规则，因此首版委托和升级材料不能假设“石头”已可获得。
- 春季有 8 个确定性采集候选点，每日激活 4～6 个；若前七天全部采集并出售，现有价格合计可产生 1,170g。Farm 有 8 块地，新游戏起始 100g，经济目标定价必须考虑采集收入，不能只按萝卜利润估算。
- 当前 `canAdvancePlayableCalendar` 在 Spring 28 明确阻止睡眠，HUD/月历也固定显示春季；R8 需要同时修改 domain 结算与两个 UI 表面。
- 当前好感为 250 点/心、每日首次交谈 +20、漏聊 -2；现有两天轮换对话位于 client，选择结果和近期历史不入存档。要实现三日去重、关系阶段、委托感谢语和一次性新阶段台词，需要把候选选择与历史状态收回 domain/save owner。
- 华强的稳定 NPC ID 是 `seed-keeper`，昊天是 `town-blacksmith`；Town 已有 `town-notice-board` inspect 点，Blacksmith 已有锻炉/工具架 inspect 点，可复用而无需新增地图。
- 当前代码、清单和 CDN 资源中没有任何音频；音频发布链路也尚未支持音频条目。可采用的首批官方候选包括 Kenney `RPG Audio` / `Impact Sounds` / `Interface Sounds`（均 CC0）、OpenGameArt `100 CC0 SFX #2`，以及按固定 sound ID 取得的 CC0 环境录音。正式采用前仍需逐文件听音、裁切/转码、哈希和 CDN 回读。
- 当前精细化总门禁仍未完成；用户本次给出的最新顺序要求先整理现版本并打 checkpoint，因此新功能实施以完成/收束该门禁和记录 checkpoint 为前置，而不是与未验收基线混写。

## Requirements

### R1 声音与设置

- 本阶段第一优先级是实际可听见的声音与环境反馈，不能只交付音频管理基础设施。
- 核心 SFX 至少覆盖：2～3 个脚步变体、锄地、浇水、砍树、敲石、收获、拾取、开门、买入、出售、对话翻页和睡觉。
- 环境声至少覆盖：Farm 风声与鸟鸣、Town 人声与环境声、Lakeshore 水声、室内房间底噪。
- 设置提供 `Master Volume`、`Music Volume`、`SFX Volume`，并保存到本地设置。
- 本阶段明确推迟 Farm、Town 配乐，不以 CC0 临时音乐占位；`Music Volume` 设置及持久化合同仍保留，为后续正式配乐使用。
- 所有第三方声音遵守仓库的官方来源、商用与再分发许可、固定版本、清单登记、同源 `/game-media/v1` 读取和 Git 不提交媒体二进制等合同。

### R2 两个长期消费目标

- 提供一个水壶升级：Day 3 由昊天开放，消耗 900g + 15 木材；Lv1 → Lv2 后沿角色面向方向一次浇最多 3 个连续有效农田格。
- 提供一个背包扩容：Day 5 由华强商店展示，消耗 1,500g；24 格 → 32 格。
- 水壶升级与昊天/铁匠铺产生实际关联；背包扩容在首周内被玩家明确看到。
- 定价与材料以积极游玩的玩家在第一周末至少能够完成其中一个目标为准，另一个作为后续储蓄目标。
- 不为工具升级引入耐久、体力、修理、品质树或通用升级树。

### R3 隐藏空洞制作入口

- 正式 UI 暂时隐藏制作入口，保留底层制作实现。
- 移除或不展示“玩家开局已有斧头、唯一配方仍为斧头”的无意义正式体验。
- 本阶段不为保留制作 UI 新增凑数配方、无功能道具或装饰品。

### R4 小镇每日委托板

- Day 1 只提示委托板将在次日开放；从 Day 2 起每个游戏日恰好生成 1 个当日委托。
- 委托从 8 条手工模板中按日期确定性轮换，指定现有 NPC、现有物品、数量、金币奖励和关系奖励。
- 当日委托只能交给对应 NPC；完成后获得 Gold + Friendship，并触发专属感谢语。
- 睡觉后刷新；刷新页面或继续游戏时，同一日期的委托保持一致，不能靠反复载入刷任务。
- 只使用最小 `DailyRequest` 数据合同，不建立 Quest Graph、任务链、条件编辑器或通用任务引擎。
- Day 6 出现一个奖励更高、要求也更高的委托；要求应来自现有能力，不引入战斗、天气或其他本阶段外系统。

### R5 关系内容兑现

- 8 名居民达到 1 心后，各有一组明显更熟悉的关系阶段台词。
- Seed Keeper 与昊天各有一个很短的 2 心事件。
- 委托完成增加关系，当天对应 NPC 优先播放专属感谢语。
- UI 暂不强调尚无内容支撑的十颗空心；外显关系以“陌生 → 熟悉 → 友好”或只突出已有内容的前两颗心为准，内部好感点与未来十心合同保留。
- 不实现生日、婚恋、复杂礼物喜好、完整送礼系统或大型心事件。

### R6 对话组合与近期去重

- 对话候选按“当前活动/状态、委托相关、关系阶段、地点/时段、人物性格”等上下文组合，工作、回家、巡山、湖岸状态保持最高上下文优先级。
- 同一 NPC 三个游戏日内不得重复完全相同的 `dialogueId`。
- 完成委托后的当天优先感谢语；达到新关系阶段后至少一次优先播放新台词。
- 每名居民只补充少量高质量性格台词，不扩建为 `8 人 × 4 时段 × 7 天` 内容矩阵。
- 对话历史随存档恢复，刷新页面不能绕过去重和一次性优先播放合同。

### R7 Day 1～7 轻引导章节

- Day 1：种田、商店和小镇。
- Day 2：委托板开放。
- Day 3：铁匠介绍水壶升级。
- Day 4：首次居民关系变化得到明确反馈。
- Day 5：背包扩容目标出现。
- Day 6：更高奖励、更高要求的委托。
- Day 7：镜门、异域传闻或奇怪材料的视觉与叙事预告，不实现战斗或远征玩法。
- 引导应复用现有世界和 NPC，以小规模触发与内容为主，不建设通用章节、教程或任务引擎。

### R8 日历连续性与存档

- Spring 28 不是硬终点；在 Summer 实现前继续使用无上限 `Day N`。
- Day 28 后存档仍可继续，不重置关系、商店、作物、委托、升级或背包容量，不进入缺少内容的错误季节。
- UI 不承诺尚未实现的完整四季。
- 刷新或继续游戏后恢复 Day、Gold、当日委托及完成状态、水壶等级、背包容量、关系状态、对话近期历史、音量设置和 Day 1～7 一次性触发状态。

### R9 范围约束

- 仍以本地单人 `GameSession` + IndexedDB 为唯一实时玩法与存档边界，不引入账号、云存档、服务端 tick、WebSocket、Colyseus、Prisma 或数据库依赖。
- 规则归属 domain/GameSession；Phaser/Vue 只发送本地命令并渲染只读 snapshot。
- 本阶段不做动物、钓鱼、矿洞、天气、节日、烹饪、装修与自由建造、完整任务系统、完整送礼系统、婚恋、大量新作物、完整 Expedition、灵兽、肉鸽或塔防。

## Acceptance Criteria

- [ ] 从新游戏实际玩到 Day 7，每隔一两天都有新的目标或清晰反馈，Day 1～7 节奏符合 R7。
- [ ] Farm、Town、Lakeshore 和室内均有可区分的真实环境声音层次，所有列出的核心交互均有真实 SFX；音量滑杆立即生效并可在刷新后恢复。
- [ ] 金币存在水壶 Lv2 与 32 格背包两个清晰消费目标；按首周平衡，积极游玩的玩家到 Day 7 至少能完成其中一个。
- [ ] 水壶 Lv2 能沿面向方向一次浇 3 格，边缘、不可浇地块和已浇地块遵循现有种田规则且不会产生越界或重复副作用。
- [ ] 背包从 24 格安全扩为 32 格，现有物品与快捷栏不会丢失或错位。
- [ ] 正式 UI 不再展示只有无意义斧头配方的制作入口，底层制作实现仍保留。
- [ ] 委托板每天展示且只允许完成一个确定性委托；刷新/继续游戏不会换任务或重复领奖。
- [ ] 委托仅复用现有物品，完成后 Gold 与 Friendship 恰好结算一次，并优先出现对应 NPC 的感谢语。
- [ ] 8 名居民达到 1 心时均能感受到台词变化；Seed Keeper 与昊天的 2 心短事件各自只按合同触发一次。
- [ ] 同一 NPC 在最近三个游戏日内不重复相同 `dialogueId`，状态台词、感谢语和新关系阶段台词的优先级满足 R6。
- [ ] Day 28 后至少继续到 Day 29，作物、商店、关系、委托、升级和存档均不重置且 UI 不进入未实现季节。
- [ ] 刷新或继续游戏后，Day、Gold、委托、升级、背包、关系、对话历史、音量和首周触发状态全部恢复。
- [ ] Day 7 只通过视觉/叙事预告制造对镜门另一边的兴趣，不引入 Expedition 实际玩法。
- [ ] 最小相关类型检查与客户端构建通过；由人工完成桌面与手机/高缩放下的新游戏至 Day 7 体验及实际听音验收。
