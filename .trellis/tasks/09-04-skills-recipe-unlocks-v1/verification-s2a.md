# 土豆基础产出与首批技能成长

2026-09-09。本轮按用户确认的连续开发方向，完成 S1-D 土豆基础产出和 S2-A 三条已核实经验路径。任务继续 `in_progress`，不代表完整技能、原作校准或真人验收完成。

## 实际行为

- 土豆统一为 `potato/potato-seed`：6 天生长、种价 50、普通售价 80、食用恢复 25。删除旧 55% / 15% 且最多 3 个的分支。
- 基础额外产出采用 0.2 的几何分布；用项目既有稳定哈希与反函数一次计算，避免无界重试循环。同地块、同播种日和收获序号的结果稳定，不因满包整理或保存重试改变。采用 32 位随机精度，不声称与原作同 seed 逐次结果一致。每日运气的额外影响尚未接入。
- 六种作物每株收获的种植经验分别为防风草 8、花椰菜 23、青豆 9、羽衣甘蓝 17、蓝爵士 10、土豆 14；土豆多产不倍增经验。镰刀按实际成功收获株数增加。
- 砍倒普通树 / 清普通树桩获得采集 14 / 2，破坏当前地表石块获得采矿 1。经验在成功候选内更新，失败不发布，保存重试不再次执行劳动。
- 三技能有累计经验与即时 0–10 级；每级对应工具少消耗 0.1 体力。锄头 / 水壶对应种植，斧头对应采集，镐对应采矿。动作按原等级扣费，升级影响下一次动作；Lv2 水壶仍按项目既有逐格规则扣费。
- 菜单新增只读生活技能页。日结报告持久记录当日等级差，升级后的次日恢复 270 体力；报告经既有确认命令清除，不另建保存链。
- 当前封套 7 / 状态 19。`skills` 保存 xp、level、reportedLevel；后者只代表日结展示记录，不代表领取配方或职业。旧档拒绝且保留，不自动迁移或重置。
