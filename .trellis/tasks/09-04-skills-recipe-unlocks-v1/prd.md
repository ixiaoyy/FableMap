# 技能与配方解锁 v1

## S2-B 首个可用配方奖励：稻草人

在连续开发授权下，接入种植 1 级稻草人配方、铁匠煤炭购买、制作 / 摆放 / 回收和隔夜乌鸦保护。使用现有库存、世界对象与候选保存链；升级当日不能提前制作，夜间报告确认成功后学会配方。原木斧制作占位移除，普通箱默认配方保留。

配方为木材 50 / 煤炭 1 / 纤维 20；煤炭第一年买价 150，第二年起 250，出货价 15。稻草人不能出货；放置于农场，占一格、阻挡通行，回收重置驱赶计数。范围为中心在内的 249 格。

乌鸦在隔夜作物生长后判定：每 16 株产生一个机会，最多 4 个，每个 30% 触发，最多 10 次从当前已表示的地形要素格查找可食作物。种子与紧接种子的生长阶段不被吃；保护与损失随日结候选一次保存并在报告显示。

验收包含未解锁拒绝、材料不足 / 满包整次不变、夜间学会 / 失败重试、离柜拒绝购买、关门拒绝新进入但屋内继续交易、合法摆放与回收、249 格边界、少于16株无乌鸦、保护与损失重试不重抽。基础肥料及其它配方仍待其真实系统，不能把稻草人当作种植1级全部奖励完成。

当前进度：S2-B 已接入首个真实配方奖励及保护，见 [最新验证记录](verification-s2b.md)。此前技能和作物批次保留，品质、其它配方、职业、钓鱼等要求继续有效。

2026-09-09：本任务属于完整复刻第一阶段，保持 `in_progress`。S0 体力前置和用户本日进一步批准的 S1-A 两种作物基础内容已接入，真人验收待反馈；完整技能尚未实施。研究见 [内容与经验对照](research/content-xp-2026-09-09.md)，结果见 [S0](verification-s0.md) / [S1-A](verification-s1a.md)。

## Goal

先为已有种田、采集、钓鱼和采矿建立可恢复的经验等级、配方解锁、熟练度与 5/10 级职业选择，并建立可由后续战斗 child 接入第五条 Combat skill 的同一合同。

## Background

- 当前 Godot 成功劳动会改变物品、资源或农田，但状态没有技能 XP/等级；制作表有木斧和普通箱两条配方，其中木斧仍为旧占位。
- 当前体力成本固定；参考作品的对应技能会同时解锁配方并提高相关工具熟练度，因此两条效果都要进入 child 设计，不能只保留方便实现的一半。
- 六种现有作物、六种自定义鱼和部分地表资源尚未完成原作映射。参考数字必须绑定明确内容和动作来源；当前内容位置、名称和数量不是第一阶段的最终上限。

## Requirements

- 本 child 先交付 farming、foraging、fishing、mining 四条已有劳动技能，每条使用 0–10 级；后续 `full-mine-combat-v1` 以同一 schema 接入第五条 Combat，不另建成长系统。child 必须先建立精确 action→XP 表：Farming 主要来自收获与照料动物，不把锄地/浇水泛化为 XP；Foraging 来自地面采集与砍树；Fishing 来自成功捕获；Mining 来自破坏石块/矿点。
- 等级与累计 XP 写入 current save；同一 impact、重试、刷新、失败动作或表现动画不能重复授予。
- 普通等级解锁对应配方；5 级和 10 级的职业名称、收益、分支依赖及生效时点按原作核对。第一阶段不擅自改为原创职业，也不只展示没有实际效果的选项。
- 等级提高对应工具熟练度/体力效率；内部精度、显示取整和现有整数 stamina 的改造必须在 design 中明确，不能凭感觉改公式。
- XP 达阈值后的 level/熟练度按参考时点立即生效；新配方提示与 5/10 级职业选择在睡眠保存成功后的升级界面生效。两个时点必须分开验证，不能全部推迟或全部即时。

## Acceptance Criteria

- [ ] 精确 action→XP 表与参考一致：收获/照料、采集/砍树、成功捕鱼、破坏石块/矿点分别只增加对应 XP；失败、锄地/浇水、错误工具和重放保持不变。
- [ ] 等级、XP 与已解锁配方在 current save 刷新/继续后保持，日结失败不提前展示或写入升级。
- [ ] 等级配方、熟练度与 5/10 级职业选择均由 Godot domain/current save 持有，不由日期或界面硬编码。

## 已批准批次：S1-A 防风草与花椰菜基础内容

目的：先消除可直接核实的内容差异，使后续种植 XP 有明确对象。此批已完成代码接入，不代表整个种植或技能系统完成；下方完整真人验收仍保留待办。

- 将当前萝卜及种子替换为防风草及种子；生长 4 天、种价 20、普通售价 35、食用恢复 25。对应初始物品、委托、送礼引用和显示名称完整同步。
- 花椰菜改为生长 12 天、种价 80、普通售价 175、食用恢复 75。
- 保留原有买种、播种、浇水、收获、食用和出货入口及一次候选保存机制；金额与体力变化按上述新值生效。
- 尚未接入 XP 时不展示经验获得或升级奖励；研究中的 8 / 23 XP 留待实际技能批次使用，不新增无调用方字段。
- 不兼容旧开发档时明确拒绝，保留原记录，不执行迁移、覆盖或清理。具体版本见设计。
- 沿用已登记素材作为临时显示，身份替换不等于美术验收；缺少合适外观时登记缺口。新素材制作、上传与发布不属于本批。

### S1-A 验收

- [ ] 新建、商店、背包、农田、委托与送礼引用均使用同一防风草 ID；界面不再用萝卜名称解释该对象。
- [ ] 持续浇水时，播种后经过 4 / 12 次有效隔夜生长分别成熟；少一次不得提前收获，未浇水不增长。
- [ ] 买种分别扣 20 / 80；普通出售与隔夜出货每件分别结算 35 / 175；食用增加 25 / 75 且不突破 270。
- [ ] 操作失败不扣费、不增产；保存重试不重复收获或日结；继续存档保留同版本作物状态，旧版本拒绝且原记录保留。
- [ ] 代码检查与真人验收分别记录，原有素材只作为临时显示，不标记正式美术通过。

## S1-B 批准范围与剩余依赖

S1-A 与 S1-B 均已获批准；用户进一步接受 42 像素 / 混合上限 3 与满包整次拒绝两项临时镰刀规则，S1-B 三种作物已完成代码接入。土豆、野采和鱼种的替换未进入本批；其概率和特殊分支需要继续取得证据。后续批次依赖与具体文件见 `design.md` / `implement.md`。

S1-B 批准范围：小白菜替换为羽衣甘蓝、青豌豆替换为青豆、油菜花替换为蓝爵士，同时接通镰刀收获和架子阻挡。精确数值、代码范围及尚未核实的交互边界见 [S1-B 方案](research/s1b-interactions.md)，实际进度见 [阶段记录](verification-s1b.md)。土豆另批核对，不以三种内容替换代替全量春作完成。

S1-B 验收要求：正常输入能收获羽衣甘蓝且空手不能绕过；青豆在生长 / 成熟 / 复收阶段阻挡通行并可正确处理播种重叠和清除；各操作保存失败不重复产出；同版本继续可恢复。镰刀按已批准临时规则验收，T-SCYTHE-01 / 02 继续记录原作校准缺口，不转为永久差异。真人验收仍待反馈。

## S1-D 土豆基础产出（连续开发范围）

用户已确认在既定方向内连续推进研究、实现和验证。本批将春土豆与种子统一为 `potato/potato-seed`，6 天生长、种价 50、普通售价 80、食用恢复 25。移除旧 55% / 15% 且最多 3 个的产出，采用原作内容数据 `ExtraHarvestChance=0.2` 对应的基础几何分布。每日运气的额外翻倍仍为独立缺口，不伪造已接入的运气字段。

验收：基础收获至少 1 个，额外数量遵循连续成功概率且不固定封顶 3；同一地块同次收获在满包重试、保存失败重试与继续后不重抽、不重复发放。无需增加 XP 空字段，不改变此前五种作物或已批准镰刀差异。

## S2-A 首批真实经验与熟练度

接入种植、采集、采矿三条已有且经验来源已核实的路径：六种作物每株成功收获授予固定种植经验；砍倒普通树 / 清普通树桩分别为采集 14 / 2；当前地表石块破坏为采矿 1。锄地、浇水、普通清草、买卖、搬运和失败动作不授予；自定义野采、鱼类不套经验值。

累计经验与 0–10 级进入当前存档；等级即时提高对应工具熟练度，每级节省 0.1 体力。菜单显示实际等级 / 经验，日结记录当日升级；升级后的次日按参考规则恢复满体力。配方、职业和其真实效果仍为本任务必做后续项，不展示无实际用途的假解锁，也不把三技能前置批次称为完整四技能任务完成。

验收：土豆额外产物不倍增经验，镰刀按成功收获株数计经验；失败和保存重试不会重复增加；阈值跨越后下一次对应工具耗能变化且仍保留小数；日结升级记录可恢复，重复日结重试不重复升级。
