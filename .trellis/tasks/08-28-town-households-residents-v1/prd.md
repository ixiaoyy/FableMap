# Town 家庭与居民 v1

## Goal

把五栋已开放的 Town 民宅从空场景变成有明确住户的家庭空间：每栋加入一名固定居民，居民拥有独立外观、姓名、职业倾向、家庭或邻里关系和住宅专属对话，使小镇先具备可识别的人际结构，再为未来日程与好感系统提供产品依据。

## Confirmed Facts

- 当前世界有华强、昊天、阿禾三名固定 NPC；五栋民宅均可进入公共区，但 NpcSpawns 为空。
- 当前 NPC 合同只有 Tiled-owned 固定位置、`npcId`、`dialogueId` 和 `interactionType`；没有时钟、天气、日程、好感、送礼或持久 NPC 状态。
- 已登记的 VectoRaith `generic_people.png` 提供足够多的 16×32 人物，可直接增加五个不同 frame，不新增图片或 manifest 项。
- 《星露谷物语》的居民感来自家庭/住址、日常路线和好感分层；本批用户确认只先实现“5 名新居民 + 家庭关系 + 住宅对话”，日程与好感后置。

## Residents

- 西街民宅：`墨子`，西街木匠，关注门窗、木料和道路维护。
- 北街小屋：`浩南`，北街守山人，记录山路、泉水与天气迹象。
- 河畔民宅：`阿澜`，阿禾的姐姐，整理染布、河岸植物与手绘地图。
- 铁匠巷民宅：`昊美丽`，昊天的妹妹，做针线与工坊围裙修补。
- 东岸民宅：`祥子`，东岸码头看守，维护木船、绳结和湖岸标记。

## Requirements

- 五栋民宅各新增且只新增一名固定 `dialogue` NPC，位于公共起居区，不进入私人内屋、不堵住入口/出口/内屋查看点。
- 五名居民使用全局唯一 `entityId`、`npcId` 与 `dialogueId`；外观 frame 只存在 client visual profile。
- 每名居民有 3～4 句住宅专属线性对话，至少覆盖住址、职业倾向和一个与小镇地点/家庭有关的线索。
- 阿禾对话补充她与阿澜同住河畔民宅；昊天对话补充昊美丽与铁匠巷家庭关系，但二人的既有身份和位置不变。
- 家庭关系只由产品文档和对话表达，不新增 Family/Relationship domain、好感值、送礼偏好或房间解锁状态。
- NPC 点击、42px 距离、modal lock、脚底碰撞、Space presentation hit reaction 和 teardown 清理继续复用现有实现。
- 不新增图片二进制、存档字段、数据库 migration、商店、任务、日程、时钟或天气。

## Acceptance Criteria

- [x] 五栋民宅公共区各显示一名外观不同、可点击的居民，且所有入口、返回出口与私人内屋门仍可达。
- [x] 墨子、浩南、阿澜、昊美丽、祥子分别显示正确姓名与 3～4 句住宅专属对话。

- [x] 五名居民进入 WorldCatalog 全局 stable-ID 检查，未知外观或 dialogueId 明确失败。
- [x] 不新增日程、好感、送礼、任务、时间、天气、存档或数据库状态。
- [x] Town 窄合同、typecheck 与 client build 通过。

## Out of Scope

- NPC 日程、跨区域移动、寻路、时钟、星期、天气与节日。
- 好感、送礼、生日、心事件、婚恋、卧室解锁和社交面板。
- 新商店、任务、职业系统、对话树、LLM 对话或持久 NPC 状态。
- 新住宅、地图大构图、图片素材、音效或动画系统。
