# 基础加工 v1

## Goal

用少量农产加工设备验证“投入原料 → 等待游戏时间 → 取出增值品”的生产选择，让种田和养鸡产物拥有第二种用途。

## Background

- 当前物品只能直接食用、送礼、交委托、出售或用于极少量即时制作；没有持续加工中的设备状态。
- 本阶段依赖 placeable、技能/配方、四季作物和鸡蛋来源已经稳定。

## Requirements

- 首版设备集合至少覆盖作物与鸡蛋两类原料；具体设备数、名称与输入表在 child 研究中按参考资料和镜像岛已有产物确定。每台一次只接收一份合法原料。
- 设备保存 input、start/ready time 和 output；游戏时间到达后变为可取，不依赖现实计时或页面常驻。
- 投入、取货、背包满、移除设备和保存失败必须原子；有内容或产物时禁止直接移除吞物。
- 加工品拥有明确售价/食用或共建用途，但不建立通用配方脚本、管线或批量自动化。

## Acceptance Criteria

- [ ] 玩家能把已确认设备集合支持的作物/鸡蛋原料投入对应设备，跨时段/睡眠后取出增值品。
- [ ] 刷新不会跳过等待、重置计时或重复发货；背包满时成品保留在设备中。
- [ ] 已确认设备集合复用同一受控状态机，但客户端不计算完成时间或价值。

## Reference Discipline

- 参考作品的 Artisan Equipment 是“一台一次处理一个 input、经过游戏时间后取 output”的核心合同；具体设备、合法原料、时间与售价在 child 研究中从现有作物/鸡蛋需求反推并引用资料。
- 父任务允许缩减设备数量，但未确认具体两台设备或产物名称；child PRD 收敛前不得把建议写成既定事实。

## Out of Scope

- 酒窖、陈化、自动装填、传送带、复杂品质继承和大规模加工目录。
