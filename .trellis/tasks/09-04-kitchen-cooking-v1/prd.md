# 厨房与烹饪 v1

## Goal

通过参考作品式农舍首次升级获得厨房和冰箱，再用已学习配方把作物、鱼与蛋组合为餐食，验证配方知识、共享食材来源与原子耗材。

## Background

- Cottage 已有源码绘制的炉灶/水壶陈设，但没有农舍升级、厨房 interaction、冰箱库存或 cooking domain；不能因为画面已有炉灶就直接宣布厨房可用。
- 当前可食用品只直接恢复体力，没有组合制作或定时 buff。

## Requirements

- 先通过农舍第一次升级增加可用厨房与作为箱子的冰箱；升级经过参考建设时间，保存成功后才切换室内与功能。
- Cooking 同时读取玩家背包、主冰箱和已批准的小冰箱来源，消费顺序必须由 domain 固定，不让 Vue 扣材料。
- 首版 closed recipes 的来源从参考类别中选择并逐项登记：开局已知、技能等级、居民友谊邮件、节目或商店购买；不使用没有参考依据的“基础里程碑解锁”。配方覆盖作物、鱼和蛋三类原料。
- 烹饪一次原子消耗完整材料并产出一道餐食；背包不足、未知/未解锁配方或缺料时全部不变。
- 餐食恢复体力；参考作品中的健康因用户已确认无战斗而不进入本阶段。是否包含食物 buff 必须在 child 研究后列出参考事实与有意偏离，不能预先删掉或自创。

## Acceptance Criteria

- [ ] 玩家能从至少三类现有原料完成多道菜，配方锁定/解锁、缺料和背包满反馈明确。
- [ ] 烹饪与食用在 current save、刷新和快速重复输入下不重复扣料或发餐。
- [ ] 厨房面板满足键盘、鼠标、触摸、焦点锁与 200% zoom。

## Reference Facts

- [Farmhouse](https://stardewvalleywiki.com/Farmhouse)：第一次农舍升级耗时三天，增加厨房与可作为箱子的冰箱。
- [Cooking](https://stardewvalleywiki.com/Cooking)：配方需先学习；厨房从背包与冰箱读取食材，部分食物除恢复外还提供 buff。
- 父任务允许缩减菜谱内容量，但没有确认菜谱数量；child PRD 收敛前不得自行填写。

## Out of Scope

- 第二/第三次农舍升级、菜谱收藏、品质、多人烹饪和大量菜品内容。
