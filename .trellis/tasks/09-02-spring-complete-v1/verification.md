## Bug Analysis: 输入与持久化的跨层边界

### 1. Root Cause Category

B/C/E：新增交互未完全沿用现有输入/保存边界。鱼获走 tick 而非 dispatch，原命令侧失败通知覆盖不到；Phaser 全局按键取消了 DOM 原生激活；触摸移动绕开键盘朝向，canvas margin 又穿出容器。

### 2. Why Fixes Failed

没有用重复重试替代修复。雨天一次旧模块结果先通过源文件、聚焦检查和实际服务内容区分，随后改用生产构建预览，避免据旧运行态修改正确规则。

### 3. Prevention Mechanisms

| 边界 | 已落实的约束 |
|---|---|
| 关键保存 | 日结先保存候选；鱼获带 saving/saved/failed，失败只能重试同一状态 |
| 输入 | DOM 激活/模态隔离；触摸朝向来自 snapshot；失焦/模态/全局松手停止 held timer |
| 布局 | Phaser host 独立 formatting context，焦点恢复 preventScroll，钓鱼高度扣除底部预留 |
| 验证 | 保留窄回归检查、真实地图可达点和生产预览；不建设新测试平台 |

### 4. Systematic Expansion

同类规则适用于未来新增 tick 产出、工具输入、弹框和局部 HUD，不扩展为通用剧情/活动框架。
