# 春季基础玩法 v1

实施状态（2026-09-03）：已按用户批准范围完成代码与相关自动检查，用户随后要求提交推送 main；真人验收仍待完成，发布结果以流水线为准。实际参数、输入/持久化边界见 design.md，检查证据和待验项见 verification.md。

## Goal

镜像岛长期定位为东方风格、拥有独立世界观和剧情故事的星露谷式生活 RPG；本任务先不展开剧情或节庆活动，在不复制《星露谷物语》具体内容并保留无上限 Day N 合同的前提下，补齐春季正常游玩所需的基础生活系统。既有 Day 1–7 路线除本 PRD 明确批准的天气、体力、自由耕作、钓鱼引导和镜门删除外保持兼容。

## Background

- 当前生产基线已有 12 个区域、8 名 NPC、06:00–24:00 时钟、昼夜表现、3 种春季作物、2 种每日采集物、8 格农田、8 条循环委托、水壶/背包升级、基础好感、动态对话和本地 IndexedDB 恢复。
- 产品方向已经确认：借鉴《星露谷物语》的生活循环、季节节奏和系统互相回收，但美术、世界观、角色、剧情、节庆、文本、奖励与长期谜团必须采用镜像岛自己的东方表达；独立剧情和节庆活动在正常游玩稳定后另立任务。
- Day 1–7 已完成人体验收；本任务只按用户最新决定删除 Day 7 镜门伏笔并用普通生活引导替代，其余首周主路线不重新设计。现有一次性进展节点止于 Day 7，Day 8 后委托按 8 条固定内容循环。
- 当前 `playableCalendarAt` 把所有绝对日期投影为 spring content。历史明确决定要求 Spring 28 不能成为硬终点，不能因为尚无 Summer 内容而阻止 Day 29 继续游玩。
- 当前 24:00 后时钟停止但世界操作仍可继续；树木砍伐后不恢复。地图共有 38 棵可砍树，最多提供 114 木材，而 Day 2–28 全部木材委托合计需要 141 木材，水壶升级另需 15 木材。
- 天气、节日、送礼、钓鱼、采矿、体力、品质/肥料和复杂经济此前均为明确后置项；本任务只重新开放日程、体力、资源再生、天气、六种作物、钓鱼、基础送礼和商店营业日程，不自动授权生产代码实施。

## Reference Rule

- 对本 PRD 已明确纳入范围的日常机制，如果细节没有单独决定，默认以当前《星露谷物语》公开规则和玩家体验作为行为参考，再按镜像岛的 GameSession、Phaser/Vue、IndexedDB、东方视觉与原创内容边界做最小适配。
- 用户最新明确决定、镜像岛既有技术合同和已确认的范围收缩优先于参考游戏；参考规则不得自动引入本 PRD Out of Scope 中的系统，也不得复制品牌、角色、地图、文案、音乐、UI 或素材。

## Requirements

### R1 — 连续日历与正常游玩

- 保留绝对 `Day N` 与星期投影；Day 1–6 的核心目标和委托保持可达，但允许本 PRD 新增的天气、体力、自由耕作和资源规则改变具体操作过程；Day 7 只把镜门预告替换为钓鱼引导。
- Day 8–28 不要求剧情节点、节庆或分周解锁；新增系统通过日常种田、采集、钓鱼、商店和天气自然形成重复游玩差异。
- Spring 28 不举行活动、不触发剧情或月度工程，只正常日结；不能阻塞 Day 29，也不能进入空内容 Summer。
- Day 29 及以后在后续季节包交付前继续使用兼容的 spring-content 规则。

### R2 — 06:00–02:00 日程与可持续资源

- 已确认参考《星露谷物语》的日周期：游戏时间从 06:00 持续到次日 02:00，24:00 时提醒玩家已深夜，但不立即停止生产行为或强制回家。
- 24:00 深夜提醒每个游戏日最多出现一次；提醒后玩家仍可行动或主动回 Cottage 睡觉。
- 到达 02:00 时玩家必定昏倒，立即停止世界输入，并复用主动睡觉的同一原子日结 owner；完成后于次日 06:00 在 Cottage 安全位置醒来。
- 已确认在 Cottage 外因 02:00 昏倒时扣除当前 Gold 的 10%，最多扣 1000g；在 Cottage 内昏倒不扣钱，两种情况都不丢失背包物品。
- 主动睡觉与 02:00 昏倒不得在同一游戏日重复结算；存档失败时不得留下 Day、农作、委托、关系或位置的半完成状态。
- 为木材等一次性资源增加受控恢复、再生或等价可重复来源，使完整春季的批准委托与至少一个升级在正常游玩下可达。
- 已确认 Spring v1 采用固定点木材再生：树倒下后留下可继续用斧头清除的树桩；Farm 外固定树点只有在树桩清除后才进入确定性再生周期。
- 每日生成少量可拾取枯枝作为应急木材来源；枯枝刷新与树木再生均按游戏日结算和保存，不依赖现实时间或重新载入页面 reroll。
- Spring v1 不建设树种、自由种树、完整树苗阶段或任意地块树木系统。
- 资源恢复、日结、农作成长、委托过期和关系结算由 GameSession/domain 按固定顺序一次性处理。

### R3 — 基础体力

- 已确认 Spring v1 加入基础体力；体力由 GameSession/domain 持久化并作为每日农作、砍伐和钓鱼之间的共同预算。
- 成功锄地、浇水、砍伐和钓鱼消耗体力；移动、交谈、拾取、空手收获与查看界面不消耗体力，失败或无效果的输入不隐藏扣除体力。
- 体力不足时禁止对应生产动作并提供明确反馈；体力归零本身不触发昏倒，02:00 仍是唯一时间型强制昏倒点。
- 首版允许直接食用经评审的少量作物或采集物恢复体力；不建设烹饪、Buff、健康、疾病或复杂疲劳状态。
- 已确认晚睡降低次日体力恢复：24:00 前主动睡觉恢复满，24:00 后随时间单调降低，02:00 昏倒时次日仍至少恢复最大体力的 50%；具体十分钟档位由同一 domain 规则定义并在 HUD/睡前反馈中可预期。

### R4 — 春季天气

- 首版只提供晴、雨、风三种春季天气；天气由 domain 生成、保存并提供次日预告。
- 雨天自动满足室外农田当日浇水，并改变室外表现、环境声及经评审的 NPC 日程；Phaser/Vue 不复制天气规则。
- 风天提高当日枯枝候选并提供风天鱼类条件；晴天保持基础农作和鱼类池，使三种天气至少各有一项可观察玩法差异。

### R5 — 差异化农作与采集

- 已确认参考《星露谷物语》采用 Farm 可耕区域内的逐瓦片自由开垦，不再把农田限制为 8 个或 35 个预登记交互对象。
- Tiled 只拥有哪些 Farm 瓦片允许开垦；玩家面向相邻可耕瓦片使用锄头后，GameSession 按稳定坐标键动态创建农田状态。道路、水体、建筑、装饰、碰撞、出口和非 Farm 区域不可种植。
- 旧 v9 存档的 8 个固定 plot 状态必须迁移到原位置坐标；其余可耕瓦片保持隐式未开垦，迁移不得凭空生成作物或覆盖已有进度。
- 浇水壶参考普通农作规则拥有可见水量并需要在经 Tiled/地图确认的水源补满；Lv2 三格浇水继续生效，但必须按实际浇到的有效格消耗水量与体力。
- 保留萝卜、小白菜、花椰菜，并把春季作物扩展至约 6 种；新增作物必须至少覆盖再生、多产、花卉/社交或特殊来源等不同机制中的三类。
- 已确认新增青豌豆、春土豆和油菜花：青豌豆成熟后按固定间隔重复收获，春土豆单次收获具有受控多产结果，油菜花可出售和日常送礼。
- 六种作物的种子价格、生长时间、体力投入、单季可收次数和收益必须形成可解释的不同定位；随机多产由确定性存档种子或保存结果控制，刷新不得 reroll。
- 增加至少一个有日期窗口或区域条件的春季采集刷新规则，避免现有两种采集物全年式重复；它只是日常采集，不演出活动或剧情。
- 不以单纯复制更多线性“浇水若干天→收获一次”的定义充数。
- 作物品质与肥料本版本后置：它们会同时改变库存堆叠键、售价、送礼倍率、委托匹配和技能关联，应在基础体力、自由农田、六种作物与钓鱼稳定后独立规划。

### R6 — 第二重复玩法

- 优先复用 Lakeshore、旧码头与祥子，交付一个轻量钓鱼闭环；鱼类至少受地点、时段或天气中的两类条件影响。
- 已确认采用原创的“抛竿＋浮漂张力”交互：按住/松开决定抛竿距离，出现咬钩提示后及时提竿，再用同一输入把张力维持在安全区直至成功收线。
- 张力持续过高会断线，持续过低会脱钩；成功、断线、脱钩与未咬钩均给出清楚且适配鼠标、键盘和触摸的反馈。
- 不复刻《星露谷物语》的垂直追鱼条，也不在 Spring v1 加入鱼饵、浮标、钓竿等级、鱼类品质或完整钓鱼技能树。
- 删除镜门伏笔后，Day 7 的普通生活引导优先由祥子和旧码头介绍基础钓鱼，使首周仍有一个内容真实存在的新目标。
- 钓获物进入现有 Inventory，可出售，并至少服务一项普通每日委托。
- 本任务不同时建设矿洞、战斗或完整技能树。

### R7 — 小镇日常规则

- 增加工作日/休息日、营业时间和特殊日程覆盖，确保商店与 NPC 行为和日历一致。
- 已确认保留基础送礼；镜像岛不设置全镇每日送礼总数限制，玩家可在同一天分别给所有居民送礼。
- 每名普通居民每天最多收一份、每周最多两份；周限制按岛上星期结算，超限输入不消耗物品或增加关系。生日、配偶和特殊礼物例外在对应系统进入范围前不存在。
- 每名居民首版只配置少量喜欢、普通和不喜欢物品；使用现有作物、采集物和鱼，油菜花获得明确的日常送礼用途。
- 送礼通过现有 Inventory 与 NPC 交互完成，限制、物品消耗、关系变化和按周计数由 domain 保存；不通过 Vue/Phaser 猜测或回滚。
- Spring v1 不制作生日、节庆、公共活动、心事件或特殊活动地图。

### R8 — 无剧情、无活动边界

- Spring v1 不展开主线剧情，并删除现有 Day 7 湖岸镜门伏笔：不再显示异光、镜门文字、特殊提示、一次性镜门事件或未来入口暗示。
- Lakeshore 石标恢复为所有日期一致的普通环境说明；Day 7 的 TodayHint 与一次性节奏提示改为内容真实存在的正常生活活动。
- 不设置贯穿 Day 8–28 的月度工程、节令准备、收集目标、庆典或结算演出。
- 不为日常玩法建设通用任务图、事件编辑器、建筑系统或服务端状态。

### R9 — 持久化、兼容与素材

- 所有新增 durable state 继续由本地 GameSession 与版本化 IndexedDB adapter 保存；不得依赖数据库、账号、云存档或实时后端。
- 本任务所有持久字段合并进一个 StoredGame/GameState v10；同一版本内不连续增加多个 save schema，完整 v10 通过验收前不得部分部署。
- 旧 v9 存档必须显式迁移或补齐确定性默认值，保留玩家位置、背包、农田、关系、委托、事件和宠物。
- 旧存档中的 `day-7-mirror-teaser` 标记必须在兼容迁移中安全移除或作为无表现 legacy 值接受，不能导致已有存档损坏；历史 checkpoint 保持历史事实，不回写伪造旧验收结果。
- 新增图片与音频必须先走既有媒体清单、不可变 `game/media/v1` 对象和许可证审查；Git 不提交游戏图片或音频二进制。

## Acceptance Criteria

- [ ] Day 1–6 已验收路线、IndexedDB 恢复和无账号入口保持不变；Day 7 只发生经批准的镜门伏笔删除与普通生活引导替换。
- [ ] Day 8–28 可以只依靠日常系统持续游玩；Spring 28 正常日结，Day 29 保持所有持久状态继续 spring-content，不出现活动、空 Summer 或硬终点。
- [ ] 每日 24:00 恰好提醒一次但仍可行动；02:00 无论剩余状态如何都停止输入、昏倒并只执行一次日结，次日 06:00 在 Cottage 醒来。
- [ ] 01:50 主动睡觉、02:00 自动昏倒、02:00 前后打开界面和同时触发床铺交互均不会重复推进日期或重复结算。
- [ ] Cottage 外昏倒恰好扣除 `min(floor(Gold × 10%), 1000g)`，Cottage 内不扣；任何 02:00 昏倒都不删除或减少背包物品。
- [ ] 锄地、浇水、砍伐和钓鱼共享一套可见体力预算；成功动作、失败动作、食用恢复、睡觉恢复和存档重载后的数值均符合同一 domain 规则。
- [ ] 24:00 前、24:00–02:00 各代表时间与 02:00 昏倒的次日体力恢复单调且可重复，最低恢复不低于最大体力的 50%。
- [ ] 正常路线可以在 Day 28 前完成批准的木材委托集合和至少一个升级，不依赖编辑存档或无限资源漏洞。
- [ ] 树木、树桩、清桩、Farm 外固定点再生和每日枯枝在睡觉、02:00 昏倒、刷新与继续游戏后保持一致；重新载入不能额外生成木材。
- [ ] 晴、雨、风在保存恢复后稳定；雨天对浇水、室外表现和至少一类 NPC 日程产生一致影响，风天对枯枝和鱼类池产生可验证差异。
- [ ] Farm 可耕区域可以按相邻瓦片自由开垦、播种、浇水和收获，非可耕瓦片明确无效；旧 8 格农田按原坐标无损迁移。
- [ ] 浇水壶水量可见、可在批准水源补满、不会负数；Lv1/Lv2 的水量与体力消耗只对应实际生效的浇水格。
- [ ] 萝卜、小白菜、花椰菜、青豌豆、春土豆和油菜花均可购买、播种、浇水、成长、收获、出售并恢复存档；青豌豆再生和春土豆多产明显不同。
- [ ] 日期型春季采集内容可发现且不会重复领取；重新载入不能改变春土豆产量或青豌豆下一次成熟日。
- [ ] Day 7 可通过祥子与旧码头发现钓鱼；抛竿距离、咬钩窗口、张力成功/断线/脱钩和物品结算形成完整闭环，并可用鼠标、键盘和单指触摸完成。
- [ ] 工作日/休息日、营业时间和天气日程在 NPC 与商店行为中一致，不出现生日、节庆或公共活动入口。

- [ ] Day 7 及以后没有湖岸异光、“镜门未开”等剧情文本、镜门 milestone 或相关特殊提示；旧 v9 标记不会破坏存档恢复。
- [ ] v9 存档升级后保留既有进度；损坏或未知新增字段明确失败，不静默覆盖原记录。
- [ ] 桌面、手机、键盘、触摸和 200% zoom 下新增入口可发现、可操作且不会互相遮挡。

## Out of Scope

- Summer、Fall、Winter 的完整内容、地图换季与季节迁移。
- 矿洞、战斗、Expedition、Cargo、灵兽、肉鸽和塔防。
- 完整技能/职业树、畜牧、烹饪、婚恋、通用建造、家具编辑或复杂经济模拟。
- 作物/采集/鱼类品质、肥料、洒水器、乌鸦/稻草人和技能驱动的品质概率。
- 新主线剧情、镜门伏笔、异界入口或任何剧情框架；独立故事待正常游玩稳定后另立任务。
- 生日、节庆、公共活动、特殊活动地图、月度工程、春季收集目标或 Spring 28 结算演出。
- 复制《星露谷物语》的素材、角色、文本、音乐、地图、活动名称或具体节庆玩法。
- 数据库、账号、云存档或服务端实时玩法。
