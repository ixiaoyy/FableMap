# 镜门远征 Prototype 规划

> **已否决（2026-09-04）**：用户明确不喜欢并淘汰镜门远征整条提案。本文件只保留历史证据，不是未来候选或实施授权；不得启动、换名或据此恢复任何代码。

## Goal

冻结 Day 1–7 真人通过基线，并规划固定地图、轻撤离、首只灵兽与单次风险事件的 5–8 分钟镜门远征原型。

## Requirements

### R1 核心验证目标

- 验证“安全家园 → 进入镜门 → 获取战利品/灵兽 → 决定撤离或继续冒险 → 成功带回家园”是否比继续扩充普通 Stardew 内容更有吸引力。
- 单局目标 5–8 分钟；真人至少连续体验 3～5 局，观察是否出现“已经赚到但还想继续”的真实犹豫。
- 只有验证成立，才允许增加更多灵兽、地图、装备、事件或守家内容。

### R2 入口与地图

- Day 7 后复用 Lakeshore `lakeshore-waystone` 作为镜门入口；不新增普通森林出口。
- 地图固定为入口 → 区域 A → 安全撤离点，并从 A 单向分支到风险区域 B；完全不做程序生成。
- 区域 A 先提供可理解的普通收益与撤离教学；区域 B 只放精英、稀有灵兽、一个三选一事件和高价值宝箱。
- 一张精美、可读、可重复游玩的固定地图优先于多地图或随机拼接。

### R3 轻量战斗

- 只有两种敌人原型：近战追击和远程/蓄力；精英复用其中一种并强化/换皮。
- 玩家使用一套远征内固定武器/动作和 run-only 生命值；不引入装备栏、属性成长、职业、耐久、体力或通用 Combat Framework。
- HP 归零即本局失败并返回镜门前；Home Inventory 和家园进度完全不变。

### R4 Cargo 与撤离

- `Home Inventory` 在远征开始、失败和放弃时保持字节等价；远征所得只进入 runtime-only `ExpeditionCargo`。
- 区域 A 在玩家承担额外风险前提供合计约 30g 的普通 Cargo；区域 B 提供明显更高的收益。
- 成功撤离时才把 Cargo 一次性提交到 Home Inventory；容量不足时必须先在远征结算界面丢弃 Cargo，禁止部分提交、隐藏溢出箱或覆盖物品。
- 失败、主动放弃、刷新或关闭页面都丢弃本局 Cargo；刷新后从已保存的 Lakeshore 镜门前继续，不保存中途 run，也不因此升级 save schema。

### R5 首只灵兽

- 只做一只低血量 → 使用一次 run-only 灵契/捕获动作 → 必定捕获的灵兽。
- 捕获结果只有成功撤离后才写入家园持久状态；失败或刷新时本局捕获丢失。
- 首只灵兽撤离后只需要在家园可见并可识别，不做属性、技能、战斗 AI、农场自动化、升级、繁殖或图鉴框架。
- 持久化灵兽归属需要一个 v8→v9 迁移；v9 只保存已带回的 closed companion ID，不保存 ExpeditionRun/Cargo/敌人位置。

### R6 单次肉鸽事件

- 区域 B 只有一个三选一事件；选项必须改变规则或风险收益，禁止三个简单数值加成。
- 事件效果仅在当局存在，不进入家园 save，不建设通用事件 DSL、遗物库、诅咒系统或随机事件引擎。

### R7 奖励与经济边界

- 普通异域材料成功撤离后可立即出售换 Gold；稀有材料先作为收藏/未来用途，不提前建设制造链。
- run-only 武器、灵契和消耗品不进入 Home Inventory，不提前引入远征商店、补给制作、装备掉落或复杂词条。
- 不允许先写 Home Inventory 再在失败时回滚；唯一持久写入点是成功撤离 commit。

### R8 技术与产品边界

- 继续使用 Phaser 4 + Vue 3 + typed GameCommand + GameSession + 纯 TypeScript domain + IndexedDB SaveRepository；不引入服务端 tick、WebSocket、数据库、账号或云存档。
- `GameSession` 仍是唯一 mutable aggregate；Expedition domain 拥有规则，Phaser/Vue 只发送命令并渲染只读 snapshot。
- 实施前必须单独评审敌人、灵兽和地图素材的官方来源、许可、固定版本、体积与 CDN 分发；规划阶段不采用二进制。
- 本任务只产出规划并保持 `planning`；不得创建 map、Cargo、敌人、捕获或战斗代码。

## Acceptance Criteria

- [ ] PRD 明确玩家问题、5–8 分钟闭环、3～5 局成功标准和停止扩展条件。
- [ ] 固定地图、区域 A/B、撤离点、两敌人、首只灵兽和三选一事件的范围可独立验收。
- [ ] Home Inventory、runtime Cargo、成功 commit、失败/刷新 discard 与容量不足结算没有歧义。
- [ ] v9 只持久化家园已带回灵兽/必要进度，不保存远征中途状态；迁移范围可审查。
- [ ] 计划没有通用战斗、宠物、事件、随机地图、装备或服务端框架。
- [ ] checkpoint 与产品边界同步记录真人通过、远征规划重开和“实施仍未批准”。
- [ ] 用户评审 PRD/design/implement 后，才决定是否激活任务和创建实施子任务。

## Out of Scope

- 第二张远征地图、程序生成、多人、赛季、排行榜或通用关卡框架。
- 完整战斗属性/装备/技能树、Boss、掉落词条或敌人编辑器。
- 捕获概率、灵兽属性/技能/养成/农场工作、图鉴或多灵兽队伍。
- 多事件池、通用肉鸽遗物/诅咒系统、塔防或东方志怪剧情世界。
- 中途 run 恢复、远征云存档、数据库或 Tauri/Steam 集成。
