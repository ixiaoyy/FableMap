- 创建规划任务不等于批准本篇章开发，也不改变现有任务的状态与优先级。

- 同一时间先推进一个有清楚验收目标的子任务，前置关系写入该子任务，不把父任务授权视为全部子任务自动开工。

## 最小自动检查选择

本轮仅检查任务 JSON/JSONL、文档链接、编号与修改范围，不执行下列产品命令。

未来代码变更后，根据实际范围选择一次最小相关组合；发现新问题才扩大验证。

| 命令 | 适用时机 | 能证明与不能证明 |
|---|---|---|
| `npm --prefix ./apps/mirror-island run typecheck:client` | GDScript 与内容接线改变后 | Godot 解析/导入相关结果；需检查 `SCRIPT ERROR` 和 `ERROR`，不只看退出码 |
| `npm --prefix ./apps/mirror-island run build:client` | Web 内容与正式资源整合后 | Web 可导出；前置会准备媒体和地图，不用于仅文档任务 |
| `npm --prefix ./apps/mirror-island run build:windows` | Windows 打包验收时 | 原生包可生成；不能替代真实操作与视觉验收 |

不默认执行 `typecheck` 的 Prisma 前置、服务端构建、数据库验证、完整迁移对照、全量 E2E 或测试矩阵。确有真实高风险复发缺陷时，再评审一个窄检查。

## 人工验收路线

单条局部路线建议控制在 5–15 分钟，方便复现；这不是完整游戏时长估计。整篇另做一次自然顺序体验，不用诊断跳章宣称全流程通过。

| 路线 | 起点与动作 | 核对结果 | AC |
|---|---|---|---|
| M01 原世界往返 | 当前版本新档，走到小镇、进入庄园、返回农场并继续生活 | 不改既有布局/入口，不接管农场身份 | AC01、AC14 |
| M02 环境发现 | 尚未发现花园，观察知更鸟、泥土、藤蔓；静音重看提示 | 线索能理解，未知人物不剧透，钥匙不重复生成 | AC05、AC06 |
| M03 园艺状态 | 对固定花地操作，离开、睡眠、刷新和继续 | 成本与变化一致，已修复不再生，无无限刷进度 | AC08、AC10、AC12 |
| M04 轮椅与人物 | 从房间到花园，经过所有门框/转角和同伴停留点 | 无穿模、堵死、普通日程抢走人物或突然瞬移 | AC04、AC07、AC09 |
| M05 关键演出恢复 | 在三类安全边界退出，再次继续 | 起点重播/终点保留符合合同，不丢控制或越级 | AC11、AC12 |
| M06 保存失败 | 用获准的隔离本地方式制造一次必要保存失败，重试同一候选 | 不提前开门、不重复扣除、不重算剧情结果 | AC12、AC13 |
| M07 全篇自然推进 | 不用跳章，完整体验 C01–C08 | 人物转变有过程、关键情节齐全、结局实际发生 | AC02、AC03、AC09 |
| M08 结局回访 | 完成重逢后返回农场、睡眠、刷新，再到庄园 | 花园和人物保持新日常，结局不强制重复 | AC15 |
| M09 输入与可读性 | 键盘、鼠标、触摸、窄屏、中文长句、Web 200% 缩放、静音 | 无焦点丢失、输入穿透、遮挡和单通道线索 | AC16、AC17 |
| M10 正式媒体与隔离 | 检查媒体来源/清单及真实运行请求 | 素材一致，无新增在线身份/剧情依赖和 Git 媒体二进制 | AC18 |

保存失败只在明确的隔离本地环境检查，不修改共享/生产环境，不连接数据库；诊断方式与临时代码须在对应实施任务中说明并获准，结束后清理。

## 风险、暂停与回退

- O01 变化：回到分镜和身份设计，不在实现中暗自改视角。
- 内容过重：缩小当批制作量，保留八章与完整人物目标；需删故事节点时重新评审。
- 新存档状态：依项目开发档政策处理版本边界，回退程序不承诺读取新版本档。
- 素材授权/质量未满足：保持候选状态，不上传、不作为正式资源，不以占位图宣称完成。
- 同文件他人改动：改前和回退前检查完整 diff，只撤本任务变更，禁止整文件 restore。
- 本轮规划回退仅涉及本任务新文件；当前没有应用变更、依赖、数据库或远端副作用。
