# 人物、章节与庄园内容方案

## 使用说明

本文件服务于 [PRD](prd.md) 的 R02–R10。用户已要求完整人物与故事；以下章节划分、场景拆分、互动方式和资产规格仍是待评审方案。不是已编写的最终剧本，也不是实施指令。

原著依据为弗朗西丝·霍奇森·伯内特的 [The Secret Garden](https://www.gutenberg.org/files/113/113-h/113-h.htm)。保留主要情节与角色作用，游戏化动作、镜头和结局后日常属于本项目的改编设计。

## 叙事方式与待定视角

O01 未决定，暂保留两种方案，后续只能确定一种正式叙事方案，不开发两个可切换版本。

| 方案 | 如何参与 | 优点 | 需要解决的问题 |
|---|---|---|---|
| A：现有玩家作为朋友，当前推荐 | 玩家探访庄园，与玛丽同行；她保留关键发现与表达，玩家参与园艺和共同活动 | 保留镜像岛的玩家身份和日常往返 | 玛丽来庄园前的经历用序章交代；私人谈话与玩家缺席情节要安排可信的叙述位置 |
| B：篇章内扮演玛丽 | 进入篇章后亲历她的探索和关系变化，返回时恢复原玩家 | 原著主角视角直接，发现过程完整 | 原角色位置、外观、物品、时间和篇章内控制权的衔接必须重新设计并获批 |

本文件使用玛丽等原著人物描述故事责任，不默认把他们的行为交给现有玩家。无论采用哪一项，都不能把未亲历的私下事件直接变成角色已知事实。

### 人物关系的游戏表达

- 玛丽与科林：多次谈话、分歧、共同发现和再次靠近，不能只通过好感条上涨表达。
- 玛丽与迪肯：共同观察和动手，玩家可以看见彼此分享知识。
- 孩子们与本：从保持距离到能够共同照料，老园丁要有自己的态度。
- 科林与父亲：早期通过房间、谈话和缺席体现距离，结局以共同出现和返回庄园回应。
- 苏珊与孩子们：通过关注、倾听、食物和一起休息表现支持；不设计交礼品换母爱的数值。
- 莉莉亚斯与庄园：画像、旧树和花园本身承担记忆，不把每个遗留物都做成收集任务。

### C01 — 来到庄园

- **目标**：建立陌生、孤独与好奇，认识庄园生活规则。
- **场景**：序章画面、入口道路、前院、门厅、玛丽房间、服务区。
- **建议互动**：跟随带路、放置随身物品、查看窗外、与玛莎交谈、第一次自行到室外。
- **必要呈现**：交代玛丽失去父母后投奔姑父，以及主人丧妻后庄园的冷清；远行背景可用短序章，不制作另一张可经营海外地图。
- **人物变化**：从完全依赖安排到第一次主动询问和外出。
- **完成条件**：入住介绍与必要人物相识完成，室外普通探索可用。具体入口身份依赖 O01/O04。
- **恢复与失败**：未走完带路时重新进入能继续；玩家不因离队失去入口，也不会触发未见人物的介绍。

### C02 — 围墙与哭声

- **目标**：让玩家通过环境发现庄园有尚未理解的空间。
- **场景**：菜园、围墙外的小径、钥匙附近、隐藏门、第一次进入的花园、主楼走廊。
- **建议互动**：观察知更鸟停留点、查看松动泥土、拨开遮蔽物、尝试门锁；室内听见异常时配合文字/视觉提示。
- **必要呈现**：发现与进入花园的过程属于玛丽的重要行动；哭声先建立悬念，不提前用目标面板显示科林名字。
- **环境变化**：开门后出现可记住的返回路径，初见花园保留荒草与仍活着的部分。
- **完成条件**：关键发现和首次进入提交成功；哭声线索有记录，但其来源仍可未知。
- **恢复与失败**：未持有钥匙时提示锁住；重复查看不给第二把钥匙；换天不重抽藏点，不重新锁已开门。

### C03 — 一小块土地

- **目标**：把发现转化为照料与伙伴关系。
- **场景**：园艺工作区、林间小径、花园、与主人的有限会面空间。
- **建议互动**：与迪肯辨认植物、整理一处花床、共同播种/照料，观察原有枝条的生机。
- **必要呈现**：迪肯的植物和动物知识有具体作用；玛丽向主人提出土地愿望的会面不遗漏，也不改为获得庄园产权。
- **环境变化**：第一次有限整理，工具和种植痕迹可持续看到。
- **完成条件**：相识、会面和首段共同劳动完整发生；成本与重复次数等待 O03。
- **恢复与失败**：体力、工具或材料条件不足时不扣除、不标记完成；已有成果保留，返回后能继续。

### C04 — 房间里的孩子

- **目标**：让玩家认识科林本人，并经历关系建立中的不顺利。
- **场景**：特定走廊、科林房间、连接花园的普通道路。
- **建议互动**：循线找到房间、多次交谈、把室外所见带回、选择继续了解或暂时结束谈话，准备后续出行。
- **必要呈现**：保留谈话、争执与重新相处；科林的出门愿望和迪肯的加入都有前因，不能从一次见面跳到康复。
- **人物变化**：科林从陌生/防备到愿意了解花园并接受同伴。
- **完成条件**：必要关系事件完成并具备出行准备；对话选项不产生不可逆坏结局。
- **恢复与失败**：暂时离开不删除关系进度；房间未开放时从门外给出反馈，不能提前碰到剧情角色或读到后续台词。

### C05 — 第一次进入花园

- **目标**：完成故事第一次集中情绪高潮。
- **场景**：科林房间、长廊与出门路线、花园停留点、围墙梯子、种植地点。
- **建议互动**：检查路线、同行或配合推轮椅、停下来共同观察花木，参与茶点与短对话。
- **必要呈现**：迪肯推轮椅的作用、科林初见花园、本从围墙边发现孩子、科林首次站立以及本与花园的承诺均进入完整场景设计。
- **人物变化**：共同秘密扩大，本进入孩子们的活动；后续行动能力不在此全部完成。
- **完成条件**：出行、初见、老园丁与首次站立相关节点分别完成，不能只记录一条开场对话。
- **恢复与失败**：路线受阻时停在安全点并可重试；首次站立作为人物事件呈现，不做按键连打或反应速度考核。

### C06 — 一起生长

- **目标**：让变化通过共同度过的日子成立。
- **场景**：不同花床、玫瑰区域、长椅/树下、工作区、庄园室内。
- **建议互动**：分次照料植物、一起走路、休息和分享食物，观察新芽与鸟类活动；每次活动有新的交流或环境结果。
- **必要呈现**：围绕原著的共同活动组织成长，科林逐步练习与更主动参与，食欲和笑声等变化通过生活场景表达。
- **环境变化**：整理、萌发与花量增加分阶段发生，日常位置扩大。
- **完成条件**：不同成长事件完成且满足批准后的时间条件；重复同一动作不能瞬间刷完全部节点。
- **恢复与失败**：不探访不会导致人物倒退或花园永久损坏；不能因随机雨天始终无法继续。

### C07 — 画像与关怀

- **目标**：把花园与这个家庭的记忆连接起来。
- **场景**：科林房间及画像位置、花园共同休息点、苏珊到访路线。
- **建议互动**：倾听科林对画像的态度、查看已知遗留物、与苏珊共同休息和交流。
- **必要呈现**：画像的变化要尊重科林的主动性；苏珊在场的关怀不可全部压成信件文字。父亲归来的叙事线索放在 C08 收束。
- **人物变化**：人物更愿意谈论家庭和未来；不是调查凶手或搜集亡者碎片的解谜关卡。
- **完成条件**：画像相关交流与苏珊探访完成，重逢前必要关系节点齐备。
- **恢复与失败**：画像不是可出售/销毁道具；未触发的私人回忆不会提前出现在全局线索页。

### C08 — 主人归来

- **目标**：完成父子重逢，并让玩家看到庄园生活真正变化。
- **场景**：归来叙事画面、主楼、花园门、园内、返回前院的路径。
- **建议互动**：普通生活后收到明确到访提示，走向相关地点；关键重逢以完整演出呈现，随后恢复可探索状态。
- **必要呈现**：苏珊的信、主人的梦与返家、走向花园、父子重逢和一起返回庄园形成有因果的结尾。梦保持人物体验，不增设可验证的幽灵系统。
- **视角处理**：主人远行中的私人片段可用短旁白/分镜呈现，不让玩家角色无理由知道或操控这一切；形式待 O01/O04 确认。
- **完成条件**：结局演出终点保存成功后，花园与角色进入结局日常；不能在信到达时提前标记整篇完成。
- **恢复与失败**：演出中断可重来；结局保存失败不先切换至永久结局状态。再次探访不强制重播。
- **原创后续**：可再次与人物交谈、看见新活动位置并照料花园；这一段明确标记为游戏改编延伸，不伪称原著新增章节。

## 分镜卡与对白交付格式

正式编剧时，每个必要场景需填写以下字段，不能只留一句剧情摘要：

| 字段 | 要求 |
|---|---|
| 稳定场景 ID / 所属章节 | 同版本中可用于恢复，不以中文标题作存档键 |
| 原著位置与改编说明 | 记录章号，分清原著事实、压缩和新增互动 |
| 视角与已知信息 | 谁亲历、谁讲述，观众与可控角色分别知道什么 |
| 进入条件 | 地点、人物、前置事件、时间要求及不可用提示 |
| 出场人物与动作 | 台词顺序、站位、转身、道具和移动路线 |
| 玩家输入 | 可操作、可观察、可选择、只能观看的部分分别列明 |
| 结束结果 | 本节点改变的发现、进度、地点和人物状态 |
| 中断与恢复 | 安全起点、重播范围、退出路径和保存失败反馈 |
| 美术/声音清单 | 场景、帧、道具、字幕和无声替代提示 |
| 验收 | 正常路线、条件未满足、重复触发和刷新后结果 |

对白按必要剧情、当前阶段反应、可选背景三类组织。必要剧情不能被随机闲聊长期挡住；已说过的背景允许主动复读，不需要大规模对话记忆系统。

## 庄园空间规划

以下是叙事空间关系，不代表最终 Tiled 尺寸、出口坐标或必须拆成同等数量的地图文件。

```text
现有小镇
  └─ 庄园道路 ─ 前院 ─ 主楼门厅 ─ 公共长廊 ─ 玛丽房间
                    │                 ├─ 科林房间（含画像）
                    │                 ├─ 会面/书房空间
                    │                 └─ 服务区与厨房
                    └─ 菜园与工具区 ─ 林间/围墙小径 ─ 隐藏门 ─ 秘密花园
                                         └─ 苏珊来访的连接路径
```

| 空间 | 故事用途 | 规划边界 |
|---|---|---|
| 庄园道路与前院 | 到来、返家、远处建筑轮廓 | 有清楚返回小镇的路线，不挪用既有矿洞/湖岸门 |
| 主楼门厅与长廊 | 带路、规矩、声响、封闭门、轮椅出行 | 未开放房间可少量表达规模，不要求所有门可进入 |
| 玛丽房间 | 入住、玛莎交谈、阶段回顾 | 不默认增加第二张可日结的玩家床 |
| 科林房间与画像 | 关系变化和关键出行起点 | 床、窗、帘、画像、轮椅和通路成套制作 |
| 会面/书房空间 | 主人与玛丽的短会面 | 普通室内，不建立书屋、传送或藏书平台 |
| 厨房与服务区 | 日常照料、食物和家仆活动 | 食物可作剧情道具，不先建全局烹饪系统 |
| 菜园与工具区 | 老园丁工作、工具与共同劳动 | 与玩家农田规则分离，不增加新商店 |
| 林间与围墙小径 | 迪肯、动物、钥匙、隐藏入口 | 有辨识地标，避免无意义迷宫 |
| 秘密花园 | 全篇情绪中心、园艺、休息和重逢 | 同一空间跨阶段变化，保留旧树、墙体和重要地标 |
| 苏珊相关背景空间 | 来访和家庭背景 | 室内扩展按分镜必要性评审，不自动制作完整村庄或十二个家庭成员 |

### 花园的固定内容点

建议按旧入口、小径、花床、玫瑰/支架、旧树和共同休息点组织内容。它们承担不同动作与记忆，不全部采用交木材修理的同一模板。

- 初见：遮蔽与荒草中有可观察的存活植物，初次构图让玩家理解围合空间。
- 整理：局部路径和花床变得清楚，保留做过的劳动痕迹。
- 萌发：新芽、叶色、鸟类活动与共同劳动形成变化。
- 盛放：同一地点通过花量、树冠、光线和人物活动获得新的感受。
- 结局日常：保留可回访与轻量照料，状态不再次自动荒废。

阶段变化的像素素材、触发条件和作物种类需联合评审，不能只在世界上叠一个颜色滤镜。
