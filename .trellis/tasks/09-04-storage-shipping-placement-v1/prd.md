# 农场仓储与出货 v1

## Goal

完整交付 Stardew 1.6.15 对应的基础背包、制作、普通箱、农场出货与出货箱建筑服务，让玩家能够整理物资、规划空间并把当天产出稳定结算为次日资金。

## Background

- 当前背包为 24/32 格、Hotbar 为 8 格、普通物品上限通常为 99；玩家不能在完整背包内换位、拆分堆叠或使用持久容器。
- 当前制作 domain 和命令已存在，但只有一个木斧配方，客户端没有制作入口。
- 当前出售绑定营业中的华强并立即获得 Gold；Farm 没有出货队列、次日收入报告或出货箱。
- 当前 Tiled 地图只有 Collision、Water、Exit 与 Tillable；Tillable 不能代替物件摆放或农场建筑 footprint 合同，动态移动也没有统一计算资源、农田、宠物与玩家物件占用。
- 用户确认在本任务列出的系统内完整参考 Stardew 1.6.15；镜像岛保留自己的角色、地图、文本、UI 和美术。开发阶段只支持新 current save，不迁移旧开发存档。
- 建筑服务使用既有西街木匠墨子，功能映射 Robin，不新增复制角色；现有西街住宅公共区改为住宅/木匠铺共用空间并增加正式服务点。

## Requirements

### R1 - 背包、Hotbar 与升级

- 新游戏背包与 Hotbar 均为一行 12 格；五件开局工具保持前五槽，沿用已确认的默认空手状态。
- 世界中一次只使用当前 12 格 Hotbar；24/36 格背包通过轮换 12 格活动行使用，数字键/滚轮只选择当前行。世界获得焦点时以 `Tab` 向前、`Shift+Tab` 向后轮换；面板打开时两者仍用于焦点导航。移动端提供等价前后按钮，不使用浏览器会截获的 `Ctrl+Tab`。
- 完整背包菜单显示全部已解锁行，并支持指定槽换位、同物合并、整组移动、取一个、取半组和自动整理；自动整理不改变工具位置，其余物品按 item-owned 唯一 `inventorySortOrder` 合并后升序排列。
- 背包按顺序升级：2,000g 升为 24 格并从开局可买；完成后才显示 10,000g 的 36 格升级。升级由华强种子店柜台旁的独立陈列点提供，不进入普通商店列表；两次买完后陈列标识消失。
- 工具 `maxStack=1`；当前普通可堆叠物及普通箱物品统一为 `maxStack=999`。Inventory、container、shop、shipping、crafting、request/gift 与 decoder 只读取 item-owned 上限，不保留 99 的第二套规则。

### R2 - 基础制作入口

- 玩家暂停菜单提供随处可开的制作页，打开时暂停时间并锁住世界输入；基础制作只读取玩家背包，不从附近箱子取料。
- 配方显示已知状态、产物、材料和数量；缺料配方变灰并明确标出缺失材料。支持制作 1、5、25 个，触摸端提供等价数量入口。
- 制作产物先进入菜单持有状态，再由玩家放入背包；关闭、背包满、重复输入与保存失败均不得扣料后丢失产物。配方超过单页容量时可分页。
- 普通箱配方新档即已知，固定消耗 50 Wood；箱子本体不可出售且可按 999 堆叠。Workbench 邻接箱取料不进入本任务。

### R3 - 普通箱与容器交互

- 普通箱占 1x1 格，拥有稳定 identity、持久颜色和固定 36 槽；物品不腐坏。打开后同时显示箱体与完整背包，支持与 R1 相同的整组/单件/半组转移语义。
- 箱子提供放入已有堆叠与整理：前者只把背包中箱内已有类型补入对应堆叠，后者合并零散堆叠并按统一游戏顺序整理。
- 箱子可免费选择 20 种颜色或默认棕色，颜色随保存、移动与刷新保持；不增加原作没有的箱子命名。
- 空箱可用任意工具敲击或连续空手敲击回收；必须先确认背包能完整接收箱体，再原子删除世界对象。
- 非空箱不能回收。玩家用斧、镐或锄连续/持续敲击时复刻上游有界四向深度优先搜索；找到合法格后移动同一 identity，失败则箱子与内容原地不动。
- NPC 路径碰撞使用同一搜索但不提供玩家面对方向；若仍找不到合法格，箱体被销毁、内容在原位置附近成为可拾取世界掉落，箱体本身不返回。掉落拥有稳定 identity 并持久化到被完整拾取，背包满或保存失败不删除；这是镜像岛即时保存合同对原作 debris 的可靠性适配。该危险终局必须有明确反馈，不得改成静默吞物或永久安全偏离。

### R4 - 摆放与占用

- item definition 持有物件类型、footprint 与 location allowlist。普通箱首版允许 `farm`、`town`、`cottage`、`seed-shop`、`blacksmith`、`town-house-west`、`town-house-north`、`town-house`、`town-house-southwest`、`town-house-east`、`foothills` 和 `lakeshore` 共 12 个已加载 region 的 `Placeable` 格；未来普通矿洞明确禁止，未知 region 默认禁止。
- Tiled 增加独立 `Placeable` 与 `Buildable` 合同，未提供即全 false；不能用 Tillable、Collision 的反集或客户端视觉空白推断合法位置。
- 每格检查统一返回 `blocked`、`clear-on-place`、`relocate-on-place` 或 `free`，并附带受影响 identity；不能把所有动态状态压成一个布尔值。普通箱保留空耕地及地板，作物格阻挡；出货箱建筑按证据清除空耕地/肥料、树种、高草与标准路径，拒绝作物、成长树、杂草/石块/树枝和玩家，并在确认时先移开宠物。具体矩阵见 `research/stardew-building-occupancy-1.6.15.md`。
- 宠物实时位置必须进入 domain snapshot 后才参与占用；客户端坐标不能作为摆放命令的可信参数。
- 占用合同必须覆盖跨日资源再生/野采刷新，避免资源恢复后与玩家物件重叠；实施前在 design 中收敛被占用候选点的处理及参考依据，不自行更改已有再生数量、周期或确定性。

### R5 - 出货与隔夜结算

- 新档在农舍右侧预装一个稳定 ID 的 2x1 普通出货箱；它是可移动建筑，不是永久固定插槽。玩家靠近时箱盖打开。
- 玩家可打开出货箱后从完整背包投入一个或整组，也可在世界中手持物品直接使用箱体；成功投入提供动画、声音和数量反馈。
- 出货资格是独立 closed item contract；当前 29 个物品与新增箱子的资格/分类固定在 `research/current-item-shipping-matrix.md`。不能由商店收购、售价是否存在或 Shipping Collection 反推；价格继续复用唯一售价 owner。
- 所有普通出货箱共享当天队列。再次打开只显示最后一次投入的完整物品/stack；背包能完整接收时可取回并移除最后一条，不能查看或撤回更早投入。
- 睡眠 candidate 内一次性计算出货、清空队列并增加 Gold；保存失败重试同一 candidate，不得重复结算或重新计算随机结果。
- 保存成功后显示隔夜报告：按 Farming、Foraging、Fishing、Mining、Other 分类，可查看每项数量、单价、小计、分类总计和总收入；玩家确认后才关闭报告进入可操作的新一天。

### R6 - 出货箱建筑服务与墨子日程

- 墨子木匠服务提供额外普通出货箱：250g + 150 Wood，可重复购买并在 Farm 合法 2x1 footprint 即时建成。移动即时免费；只有至少另有一个普通出货箱时才能拆除，Mini-Shipping Bin 不计入保底数量。
- 服务只能在西街住宅公共区的正式木匠服务点与墨子交互开启，不能在任意地点靠近墨子远程打开，也不能复用种子店的通用 `shop` 标记。
- 当前可达日程完整映射基础营业：普通日 09:00-17:00；普通非雨周二正式休息，但墨子约 09:40 离家和 20:00 返回时经过柜台可短暂提供服务；普通雨周二恢复 09:00-17:00。普通非雨周五 16:00 离柜，经过柜台时仍可短暂服务；普通雨周五依据 Robin 页面声明的雨天最高优先级映射至 17:00。服务开放取决于实际柜台位置，日程、位置、活动与服务必须由同一 resolver 得出。
- Summer 18、关闭商店节庆、Night Market、绿雨和路过柜台窗口写入日程证据与后续合同；`four-seasons-minimum-v1` 接通真实 calendar markers，鸡舍/筒仓与农舍升级任务在出现真实施工 job 时接通施工日关闭。阶段拆分不得把这些分支永久删除，也不得提前增加无调用方状态。

### R7 - 持久化、输入与反馈

- 所有背包、制作、容器、出货、摆放和建筑写操作通过 typed GameCommand 进入 GameSession/domain，成功后只提交一次关键保存；Vue/Phaser 只保留面板焦点、当前对象和放置预览等临时表现状态。
- current save 保存背包行顺序、世界对象 identity/位置/颜色/箱内槽位、可拾取世界掉落、ID 序号、当天出货队列和未确认的隔夜出货报告；严格解码并拒绝非法类型、数量、坐标、重叠、资格或倒退序号。刷新后仍须展示尚未确认的报告。
- 箱子、制作、出货与建筑面板打开时暂停时间、锁住世界输入，支持 Escape/返回、焦点恢复、键盘焦点循环、鼠标和触摸；日结或清理会强制安全关闭。
- 桌面与移动端、200% zoom 下均能完成完整闭环。用户确认本 child 暂不新增手柄输入；不得加入未接通的按键提示或半套手柄导航。

## Acceptance Criteria

- [ ] 新档为 12 格背包/Hotbar 和五件开局工具；独立陈列点按 2,000g、10,000g 顺序扩为 24/36，活动行可轮换，普通物品达到 999 而工具仍为 1。
- [ ] 完整背包可换位、合并、整组/单件/半组移动及整理；制作页可暂停游戏、显示缺料并制作 1/5/25 个，50 Wood 箱子产物在满包、关闭与重复输入下不丢失。
- [ ] 玩家可放置、着色、打开并跨日使用 36 格箱；放入已有堆叠与整理准确，空箱可回收，非空箱的玩家/NPC 推动及极端失败完全符合 R3。
- [ ] 摆放判定能区分阻挡、随放置清除、先移开和空闲；清除/移开与建筑创建原子完成，失败不产生半清状态。同一事实源同时约束小物件、建筑、移动与 NPC 路径。
- [ ] 玩家可通过两种入口投入一个或整组，只撤回最后一次完整投入；保存成功后只结算一次，并看到分类、逐项与总收入，保存失败可重试同一 candidate。
- [ ] 玩家可按 250g + 150 Wood 即时加建出货箱，免费移动并在拆除时始终保留至少一个；所有箱共享队列且移动/拆除不复制或丢失待售内容。
- [ ] 墨子在当前可达星期/天气/分钟下的服务与人物位置一致，包含周二 09:40/20:00 和周五离柜过柜窗口；精确特殊日和施工分支都有明确后续 owner，不存在 UI 自行判断。
- [ ] current save 刷新/继续保持全部状态；桌面键盘/鼠标、移动触摸和 200% zoom 下无输入穿透、焦点丢失或不可达操作，本任务不以手柄作为验收入口。

## Out of Scope

- Workbench 邻接箱取料、Big/Stone/Junimo Chest、Mini-Shipping Bin、箱子命名、家具、物流网络、自动售卖与 Shipping Collection/成就。
- 鸡舍、筒仓、农舍升级等长周期建筑本体；它们复用本任务的 footprint 与木匠服务，并在各自 child 接入施工 job。
- 手柄输入、手柄焦点导航和手柄按键提示；当前键盘/鼠标/触摸语义不得依赖未来手柄能力。
- 复制 Stardew 的角色、地图布局、文本、UI、美术、声音或商标表达。
