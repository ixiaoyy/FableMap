# Exploration Design Thinking Guide

> **Purpose**: 在镜像岛新增秘密、环境互动、时间事件或探索区域前，先确认它增强现有生活循环，而不是扩建未经批准的大系统。

详细产品原则见 [镜像岛探索设计原则](../../../docs/EXPLORATION_DESIGN_PRINCIPLES.md)。本指南只负责立项前检查，不代替独立 PRD、工程合同或实施批准。

## 何时使用

- 新增环境秘密、隐藏点、地标、特殊工具互动或时间限定发现。
- 为 Town、Foothills、Lakeshore 或未来独立区域增加探索内容。
- 候选需求提到“冒险感”“塞尔达感”“解谜”“世界互动”或“地图更有内容”。

## 立项前检查

- [ ] 用一句话写清玩家价值和目标情绪，而不是只描述功能。
- [ ] 写清“异常 → 线索 → 动作 → 反馈 → 变化”五步体验。
- [ ] 先检索现有移动、观察、工具、NPC、时间和 snapshot 能力。
- [ ] 说明为何不能复用已有动作后，再考虑新增命令或持久状态。
- [ ] 确认秘密可选，不阻塞基础生活循环，也不依赖外部攻略。
- [ ] 让奖励改变世界、路线、知识或选择，不只发 Gold/普通材料。
- [ ] 为成功、失败、条件未满足和刷新恢复分别定义表现。
- [ ] 标出对 Farm v1、Town 固定构图、地图点位和存档版本的影响。
- [ ] 明确本次不建设的相邻能力，尤其是战斗、物理沙盒、程序生成和通用框架。
- [ ] 给出一条 5～15 分钟真人验证路线和可观察通过条件。

## 停止信号

出现任一情况时先收缩方案，不开始实现：

- 需要先建设完整框架，首批内容才有意义。
- 主要乐趣来自重复收藏、随机掉落或纯数值奖励。
- 玩家只能靠任务箭头、穷举或像素级点击发现答案。
- 候选借探索之名重开当前暂停的远征、战斗、灵兽或宠物复杂养成。
- 方案会重排已冻结地图，却没有真实碰撞或可玩性证据。

## 进入实现前

- [ ] 创建独立 Trellis 任务并获得明确批准。
- [ ] 同步 `PRODUCT_BRIEF.md`、`WHAT_NOT_TO_BUILD.md` 或相关路线图中的当前边界。
- [ ] 若新增命令、存档状态或跨层行为，在相关 code-spec 中补齐完整可执行合同。
- [ ] 只选择与该纵向切片直接相关的最小自动检查和真人路线。
