# Day 1–7 真人完整体验清单

本清单由真人执行。当前所有项目默认 pending；不要因为静态测试通过而提前勾选。

## 0. 准备与记录格式

- [ ] 使用独立浏览器 profile 或确认可覆盖本地存档；清除站点数据会永久删除该 profile 的农场与音量设置。
- [ ] 从正常公开入口 `/` 新建游戏，不显示登录、注册、论坛账号或云存档入口，也不发起 Keycloak/OIDC 请求。
- [ ] 打开 console 仅用于观察错误；不要编辑 IndexedDB 或直接改 Day/Gold/关系/事件字段。
- [ ] 每个问题记录：设备/浏览器、视口与 zoom、Day/时间/地图、操作、实际、期望、是否稳定复现。

## 1. 推荐 Day1–7 路线

这条路线优先保证 Day5 完成水壶升级；另一个背包目标保持为后续储蓄目标。

### Day 1 — 农场、商店、小镇

- [ ] TodayHint 清楚指向种田、华强商店和小镇；HUD 显示 `Day 1`，不承诺完整四季。
- [ ] 买 2 粒萝卜种子；开垦、播种、浇水，确认锄地/浇水声与动作同步。
- [ ] 砍完 Farm 8 棵树，背包得到 24 木材；斧声有反馈，点击石头只听敲石声并提示现有工具无效。
- [ ] 与华强交谈一次并记录关系；收集当天所有 Farm/Town/Foothills/Lakeshore 采集物，卖出多余物品。
- [ ] 走过 Farm、Town、Lakeshore 和至少一个室内，分别检查风鸟、城镇人声、水声与室内底噪的层次和切换。
- [ ] 回 Cottage 睡觉，确认睡觉声、淡出/淡入和一次日结。

### Day 2 — 委托板

- [ ] 粉树广场委托板可发现且显示固定委托：华强需要 6 木材，奖励 100g / 170 关系。
- [ ] 刷新并继续一次，委托不 reroll，Day/Gold/背包保持。
- [ ] 与华强交付，恰好扣 6 木材、加 100g/170 关系；重复交谈不重复领奖，当天优先感谢语。
- [ ] 继续与华强每日交谈；浇两株萝卜，收集并卖出当天多余采集物。

### Day 3 — 水壶升级目标

- [ ] 睡醒或继续后只出现一次水壶介绍提示；刷新不重复刷屏，TodayHint 持续给出 900g+15 木材目标。
- [ ] 委托固定为阿澜需要 2 朵春日野花，奖励 110g / 70 关系；交付只结算一次。
- [ ] 在昊天正确工作地点看到升级入口；资金不足时提示明确且 Gold/木材/Lv 不变。
- [ ] 与华强交谈；浇两株萝卜，收集并卖出剩余采集物。

### Day 4 — 首次关系变化

- [ ] 两株萝卜在此前三次浇水/睡觉后成熟，收获声与物品数量正确；保留给 Day5。
- [ ] 与华强连续第四天交谈后达到“熟悉”，至少一次优先播放明显更熟悉的台词；Social 只突出 2 颗内容心，不显示十颗空心承诺。
- [ ] 当日墨子 9 木材委托可以主动放弃；睡觉后自然过期，无扣钱、掉关系、伤害或其他惩罚。
- [ ] 对同一居民回看 Day1–4 记录，最近三个游戏日内没有完全相同 dialogueId/句子机械重复。

### Day 5 — 完成一个长期消费目标

- [ ] 睡醒或继续后背包扩容提示只出现一次；华强商店显示 1500g 的 24→32 格目标。
- [ ] 阿禾委托需要 2 份萝卜，奖励 150g / 80 关系；交付 Day4 收获的萝卜且只结算一次。
- [ ] 收集并卖出当日多余采集物；推荐路线此时应约为 1215g / 18 木材。
- [ ] 在昊天处购买水壶 Lv2，恰好扣 900g 和 15 木材；刷新/继续后 Lv2、Gold、木材保持。
- [ ] 回 Farm 面向连续三格农田，点击沿面向方向排列的第一格，三格有效生长作物一次浇水；不越界、不浇非连续格、不重复扣资源。
- [ ] 背包仍为 24 格且 1500g 目标清晰，形成后续储蓄动机。

### Day 6 — 高投入委托

- [ ] 委托固定为昊天需要 15 木材，奖励 320g / 100 关系，要求和收益明显高于普通日。
- [ ] 推荐路线此时木材不足；选择不完成后没有伤害、罚款、关系扣减或虚构风险系统，只有机会损失。
- [ ] 继续检查当前活动台词优先于普通性格台词，工作/回家/巡山/湖岸语境没有被破坏。

### Day 7 — 镜门预告

- [ ] 睡醒或继续后湖岸异动提示只出现一次，TodayHint 指向 Lakeshore。
- [ ] 祥子委托固定为 2 份春笋、180g / 80 关系；交付与感谢只结算一次。
- [ ] Lakeshore 石标持续显示代码绘制的镜面微光；刷新/切区再回来仍按 Day7 可见。
- [ ] 点击提示变为“查看异光”，出现三句镜门叙事并产生兴趣；结束后仍留在 Lakeshore。
- [ ] 周围没有新出口、传送、敌人、战斗、掉落、Cargo、捕获或 Expedition UI/状态。

## 2. 声音与设置

- [ ] 脚步至少能听见多个变体，连续移动不产生刺耳叠音。
- [ ] 锄地、浇水、砍树、敲石、收获、拾取均在成功/对应表现时播放；失败路径不误播成功声。
- [ ] 开门、买入、出售、对话翻页、睡觉均可听见且不过响。
- [ ] Farm 风声/鸟鸣、Town 人声/环境、Lakeshore 水声、所有室内底噪可区分；切区平滑，无明显残留双环境声。
- [ ] Master=0 静音全部；SFX=0 静音音效和环境；Music 滑杆可保存但本阶段没有音乐，不应凭空播放临时曲。
- [ ] 调整三个滑杆后刷新/继续，数值恢复；清除站点数据后恢复默认。
- [ ] 首次进入若浏览器阻止 autoplay，第一次有效点击后能重试启动声音；console 无未处理音频错误。
