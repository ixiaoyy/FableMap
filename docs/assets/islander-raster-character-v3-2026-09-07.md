# 岛民分层像素角色 v3（2026-09-07）

用户在拒绝两轮程序绘制角色后，以“这种可以”认可本轮男女四向设计。v3 依据这张图的圆润脸型、蓬松栗色头发、暖白棉布、蓝色牛仔与棕色工作靴制作。来源为项目通过 OpenAI 内置 ImageGen 制作的原创图片；星露谷官方截图仅在最初设计时研究人物比例，没有裁取其像素进入运行时。

## 对象与来源

- 颜色层：`assets/original/islander/2026-09-07-v3/character-layers-v3.png`。
- 材质遮罩：`assets/original/islander/2026-09-07-v3/character-materials-v3.png`。
- 两张图均为 432×1536 RGBA，六个角色部件来源行、三个头/上/下部件列。每个部件占 144×256，包含 48×64 的三列、四向帧。
- 精确字节、SHA-256、原始文件规格、处理步骤和注册线见同名 `.metadata.json`；真实设计与六张动画源图 prompt 见同名 `.prompts.json`。
- 制作者：镜像岛项目、OpenAI 内置 ImageGen；Codex 使用 Sharp 做透明背景提取、最近邻切片、部件归属和锚点注册。未把原 PNG 编码成程序内的像素数组。
- 原始六张图没有真实 alpha，棋盘是已烘焙 RGB 背景；采用四连通边缘提取去除，保留原件。最终图只发布上述两个必需对象，图片二进制不进入 Git。

## 客户端合同

发型、上装、下装独立选取部件，性别选择不限制服装；保留 `GameSession` 外观字段及 IndexedDB v13，无数据库、账号或存档格式修改。原生脚底 `(24,60)`，世界缩放 0.5；Vue 换装预览与 Phaser 使用同一套 PNG 部件和材质换色。

头部用各向站立帧维持面部一致性，接触帧向下沉一个像素。下装牛仔色与背带胸片同步；默认浅桃肤色、栗棕发色、暖白上装、牛仔下装严格保留原 RGB。其他颜色只作用于材质遮罩，不重绘人体或服装轮廓。

## 验收范围与已知限制

已检查透明边、四向站立和跨发型/服装组合；颈部、腰部、手部连续，换装残留的游离后颈像素归回头部。两图在共同加载成功、尺寸与 Canvas 可读性核验后才交给客户端，失败显示可重试错误，不静默回退到旧角色。

生成源中女性马尾右向第三帧存在错向，已明确排除，使用该朝向合格接触帧。侧向两端步势仍较相近，目前是短接触/站立循环，尚未达到完整交替肢体动画的最终标准；后续动作精修必须发布新的不可变版本。用户认可静态美术方向不等于认可所有动画。

本次远端范围仅为两张素材的发布 allowlist、manifest 和这三份来源文本；媒体配置提交使用 `[skip ci]`，避免无关应用部署和数据库 migration。应用源码集成在本地工作区单独处理。
