# 可换装分层角色素材（2026-09-06）

本记录对应正常单人客户端使用的原创角色绘制源码。人物由上部（头部与发型）、中部（上装与手臂）、下部（下装与鞋）独立组合；创建角色和游戏内「外观」面板共用同一套绘制函数，不再用整个人物候选图替代换装。

## 作者、来源与版本

- 制作者：镜像岛项目通过 Codex 编写原创 TypeScript 像素绘制源码。像素簇、轮廓、调色板和衣服细节直接保存在文本源码中，可逐像素修改；不声称由人工画师手工完成。
- 制作来源：项目原创代码绘图，视觉方向沿用用户选定的 A「清新田园」。没有提取《星露谷物语》或其它第三方作品的人物图像，也没有引用第三方角色素材包。
- 版本：`layered-character-2026-09-06-v2`。用户反馈 v1 形象怪异后，重画头身比例、发型与步态；外观字段、帧尺寸、图层和脚底锚点保持兼容。
- 本批未调用 ImageGen 或其它图像生成服务，没有 AI 生成的栅格源图，因此没有图像生成 prompt sidecar。Codex 辅助编写代码的来源如上，不伪造图像生成提示词或第三方素材署名。
- 原创源码：[character-art.ts](../../apps/mirror-island/client/src/game/presentation/character-art.ts)。正常构建按仓库代码交付，不新增独立素材许可证声明。

## 可编辑范围与绘制规格

| 项目 | 当前源码规格 |
|---|---|
| 单帧 | 24 × 32 原生像素，透明背景；固定脚底锚点 y30 |
| 头部层 `head` | 脸、头发；短发、波波头、马尾三种轮廓 |
| 中部层 `top` | 躯干、衣领、袖子与手；衬衫、背带装、外套 |
| 下部层 `bottom` | 腿部、鞋与下装；长裤、短裤、裙装 |
| 性别 | 男、女；轻微调整肩宽与面部像素，服装和发型不限制性别 |
| 配色 | 3 种肤色、3 种发色、4 种上装色、3 种下装色 |
| 朝向 | 向下、向左、向右、向上；右向由左向绘制过程镜像 |
| 步态 | 每方向 3 帧，步态 1 为静止，0 与 2 为交替迈步 |
| 组合顺序 | 下部 → 中部 → 头部；长发可以覆盖衣服上沿 |
| 像素处理 | 整数坐标像素簇；禁用插值，保留清晰像素边缘 |

`paintCharacterFrame(context, appearance, facing, walkStep, layer?)` 既能生成完整预览，也能单独绘制一层。它保存并恢复调用方画布变换，只清理当前 24 × 32 帧，三层使用相同的步态与身体偏移，避免头发、手臂和裤腿相互错帧。

运行时装配源码为 [LayeredPlayerArtwork.ts](../../apps/mirror-island/client/src/game/presentation/LayeredPlayerArtwork.ts)。客户端为 `head`、`top`、`bottom` 分别建立一张 **72 × 128** Canvas 图集，即 3 列步态 × 4 行朝向，每张 12 帧。固定纹理 key 为 `islander-head`、`islander-top`、`islander-bottom`；换装时重绘这三张现有图集，不按每套搭配创建无限增长的纹理 key。Phaser 使用三个实际 Sprite 叠放，中部 Sprite 驱动动画，其余两层同步帧号与动作变换。

## 使用入口与交付形式

正常入口为 `/`。新建本地农场时进入角色创建界面，已有角色可从游戏内「外观」面板编辑。角色预览与实际角色均引用上述正式源码，不依赖 `?toolArt=preview`；该参数此前用于工具、小屋和室内图片试样，与本批角色交付边界无关。

本批没有新增静态 PNG、WebP、图片 URL 或 `game/media/v1` 对象，也没有新增需要上传的图片二进制。三张图集仅为浏览器运行时 Canvas 内存纹理，不作为图片文件写入 Git、IndexedDB 或 CDN。因此本记录不预填图片 MIME、CDN 缓存头或生产媒体清单对象；玩家外观保存的是可验证的性别、部件与颜色选项，图片本身不进入存档。

## v2 比例与轮廓重画

参考已实际查看的[星露谷官方媒体页](https://www.stardewvalley.net/media/)及其中[农场截图](https://www.stardewvalley.net/wp-content/uploads/2012/04/StardewValley_9-1024x587.png)，观察人物头宽与肩宽的关系、自然下垂的双臂、裤腿长度与小鞋轮廓。该图只作为视觉研究，不是本项目采用或可再分发的角色素材；下述像素坐标为项目自定规格，不宣称精确复制参考人物。

- 头部主轮廓由约 16px 收至 10–12px，短发、波波头与马尾分别绘制。减少零碎高光，短发用侧分缺口与不对称鬓角，额发和眼睛分离，下颌收为圆角。
- 衣服改为收腰的躯干与 2px 手臂，上提下摆；长裤露出更长的裤腿，短裙改为少量连续褶皱，小鞋替换原厚方靴。
- 侧向两步交换髋、膝、脚的前后关系，保持左右迈步幅度对称；正背面由支撑腿与摆动腿交替承重。三层仍共用 12 张原生帧，世界和 UI 预览都以 `0,1,2,1`、6fps 播放。
- 所有服装及性别共用闲置手心：正背面 `(7,21.5)` / `(17,21.5)`，左侧近手 `(13,21.5)`，右侧近手 `(11,21.5)`。工具按 y30 脚底换算锚点，移除原长袖额外偏移，预览脚底阴影同步缩小。
