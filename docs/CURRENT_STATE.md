## 当前产品

- 唯一产品是 `apps/mirror-island/` 下的单人 Web 像素生活 RPG，公开入口为 `/`。
- 客户端采用 Phaser 4 + Vue 3 + TypeScript + Vite + Tiled；玩法由本地 GameSession 处理并保存到 IndexedDB。
- 当前公开试玩无账号、无云存档、无实时后端依赖；同一浏览器 profile 只有一个本地农场。
