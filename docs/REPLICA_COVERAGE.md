# 第一阶段复刻差异表

2026-09-08 首轮盘点。以当前 Godot 源码和内容表为实现证据，区分已有能力与原作对齐程度。此表是持续补齐的入口，还没有展开到原作每个物品、角色、配方、事件和区域，不能据此宣称全量核对完成。

## 已核对的优先差异

| 范围 | 当前代码事实 | 原作对照或缺口 | 下一步 |
|---|---|---|---|
| 体力 | S0 已改为 270 基础上限、小数保存、食用与正常/晚睡恢复 | 疲劳、负体力、永久上限成长和特殊恢复仍有缺口 | 继续后续批次，不宣称完整体力系统已完成 |
| 基础耗能 | 锄地/砍树/采石为 2，单格浇水为 2，抛竿为 8 | 熟练度、失败挥空与疲劳等分支未接入；当前 Lv2 逐格浇水仍是中间规则 | 在技能和工具对齐批次继续处理 |
| 水壶 | 容量 20/40，两档升级；升级为即时木材/金币服务 | 不等于原作完整金属等级、容量、蓄力与升级等待流程 | 工具升级任务完整对照，不能把现有 Lv2 直接等同铜级 |
| 作物 | 六种自定义春作；萝卜 3 天，花椰菜 8 天、售价 170 | 种类、命名、生长期和价格都需逐项重核 | 内容对齐批次，不直接给自定义作物套原作 XP |
| 钓鱼 | 六种自定义鱼、按张力 22–78 推进捕获，没有原作难度/品质字段 | 需要重做鱼种映射、小游戏与 XP 所依赖字段 | 独立钓鱼对齐批次 |
| 技能 | 没有 XP、等级、职业或熟练度状态 | 技能任务仍为 planning，且旧的原创职业要求已过时 | 先落实依赖，再逐步完成技能任务 |
| 配方 | 只有默认木斧和普通箱两条配方 | 技能配方依赖肥料、自动化、加工、鱼饵等实际可用系统；木斧制作是旧占位 | 清理占位并按各系统接入真实奖励，不能仅做解锁提示 |
| 存档 | S0 使用 Godot 封套版本 2、状态版本 14，体力允许有限小数 | 尚无技能成长字段；旧封套明确拒绝 | 不自动迁移或改写旧记录 |

实现证据：`apps/mirror-island/godot/data/rules.json`、`domain/resource_rules.gd`、`domain/fishing_rules.gd`、`domain/game_session.gd`、`persistence/save_codec.gd`。原作依据和版本限制见 [技能前置研究](../.trellis/tasks/09-04-skills-recipe-unlocks-v1/research/baseline.md)。
