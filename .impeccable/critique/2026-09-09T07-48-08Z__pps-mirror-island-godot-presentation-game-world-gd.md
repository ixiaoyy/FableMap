**验收结论：不通过正式美术完成验收；当前可作为开发占位版继续使用。**

日期：2026-09-09。对象为当前 Godot 导出的已实现功能，标准为 `docs/IMAGE_ASSETS_SPEC.md` 的 A 清新田园。这里判断的是画面和功能表现是否达到标准，不以代码存在或构建成功代替美术完成，也不代签用户的最终审美认可。

当前作品已经有像素农场的身份：春绿、清蓝池水、桃橙屋顶和暖白 UI 建立了基调。最大问题是素材、状态和动作没有成套闭合：有的内容换了名称但没有换形象，有的行为只体现在文字中，同屏资产的像素尺度也不同。

**检查范围与证据**

- 独立 A 负责视觉判断，独立 B 负责资源和调用链；两者未读取彼此结果，主任务在 A 完成后才合并 B。
- 实际查看当前普通导出的启动页、角色创建、农场、小屋、制作与菜单，以及 390×844 的小屋和菜单。A/B 另查看已有内存 QA 场景中的稻草人、煤炭和制作；该 QA 包部分面板尺寸早于最终收紧，不用于判定当前稻草人面板大小。
- 从当前 `media.json` 实际取帧，生成了六作物和全部物品对照图。种子基础图标另有运行时徽记，对照图未叠加徽记，不能据此说运行时种子完全相同。
- 未逐一实走其余区域、八名 NPC 日程、猫狗、全部工具四向完整动作、钓鱼、雨夜、每株作物完整生长过程和真机。对应项保持待验，不据静态接线签通过。
- 本轮未修改游戏代码、配置、玩法或验收状态，未构建或跑游戏测试。新建的测试农场仅位于独立本地测试端口，没有使用用户原有农场；评审文件和证据图是本轮产物。

**优先整改项**

1. **P1：窄屏室内构图被裁切。** 390×844 小屋中，左侧床和右侧灶台都不完整；源码 `game_world.gd:233-239` 在普通室内固定 `camera.zoom=Vector2(2,2)` 并使用房间锚点。需要按可用视口调整室内缩放或跟随范围，确保必要家具完整可见，不只调整菜单尺寸。整改类型：adapt。

2. **P1：作物的名称、收获物和可交互形象未同步。** 蓝爵士仍是黄色花；羽衣甘蓝仍借用小白菜形象；防风草和青豆也沿用旧帧。青豆逻辑已阻挡通行，但当前生长 / 成熟图没有清楚的架子。六种物品图标又直接复用成熟植株，土豆等收获物像带叶整株，而非收获后的物品。生长仅在两帧间切换，并缩放同一未成熟图。应成组对齐种子徽记、独立收获物、成长阶段和架子形象。新测试农场没有种植操作时已经看到田块和植株装饰，而 `rules.json:487` 初始 farmTiles 为空；这会制造可收获的暗示，应区分装饰与状态驱动对象。整改类型：clarify / polish。

3. **P1：已实现行为缺少对应的世界表现。** 乌鸦目前只有损失 / 驱赶结算与文字，没有鸟的图像、飞入、啄食或被驱赶表现；钓鱼目前主要进入进度条面板，缺少世界中的鱼线、浮漂、抛竿和上鱼过程。八名 NPC 的移动来自单帧翻转 / 轻微摇摆，职业活动用单字标签表达，不能算完整走路或劳作动画。应按已存在的玩法事件补表现，不重写规则。五件工具已经有程序动作，不属于完全没有动画，但本轮没有逐方向验收其质量。整改类型：animate。

4. **P1：同屏风格和材质密度不统一。** 玩家细节较密，基础工具粗黑，稻草人较扁平，环境处于另一档颗粒；五件工具的轮廓厚度、木柄和金属明暗也不成套。农舍外墙和梁柱大量深褐色，与已选暖白墙面、浅木材质有距离；小屋内部反而更接近清新田园。应先以同一农场镜头统一房屋、人物、工具、植被和稻草人，保持现有地图拓扑。新的五工具图集仍是本地候选，不能当成普通导出已采用。整改类型：colorize / polish。

5. **P2：制作和成长界面过于依赖文字。** 当前普通制作页仅一条配方时仍有大面积空白；产物和材料是全宽文字按钮，图像主要留在下方背包。技能、配方解锁和乌鸦日结也缺少图像层级。应复用真实物品 / 技能图标，突出产物与变化，按内容收紧面板；不需要给每个数字添加强动画。整改类型：layout / polish。

**可以保留的部分**

- 农场池塘、岩岸、荷叶和少量花簇可读，像素边缘清楚，没有靠模糊缩放掩盖问题。
- 小屋室内的浅木地板、奶油墙面、蓝白床品和薄荷柜体较接近既定方向；桌面构图可作为继续精修的基础。
- HUD 的时间、金币、体力与背包分区明确；稻草人在世界和物品栏中的轮廓一致，煤炭可辨认。这些可支撑当前功能识别，但不等于整套资产已正式验收。

**对不同玩家的影响**

首次进入的玩家会把装饰植株或黄色花图标当作真实种植物来理解，难以从画面判断能否收获、能否穿过。持续经营的玩家会反复进入内容偏少的大制作面板。窄屏玩家则直接面临重要家具被截断的问题。这三类问题应先于增加更多装饰解决。

地表微噪点、重复方框田地和过于均匀的道路边缘属于次要精修项。先减少底纹竞争，再用少量草簇、阴影和生长差异组织重点；不要重排地图来掩盖资产问题。
